## 2. Разбор контрольных вопросов (с пояснениями)

### 2.1. Какой редактор используется в ОС Linux по умолчанию?

**Вопрос:** *Какой редактор используется в ОС Linux по умолчанию?*

**Варианты ответов:**
- `pico`
- **`vim`**
- `nano`

**Правильный ответ:** `vim`

**Разбор:**
- В большинстве дистрибутивов Linux по умолчанию присутствует `vi` (или `vim`). Это стандарт для серверных ОС и минимальных установок.
- `nano` часто предустановлен, но не является «редактором по умолчанию» в том смысле, в каком им является `vi`/`vim`.
- `pico` — устаревший редактор, практически не используется в современных дистрибутивах.

> **Примечание:** В некоторых сборках (например, Ubuntu 24.04) `vim` может не быть предустановлен — вместо него идёт `nano` или `vi-tiny`. Это особенность конкретной сборки, но в общем случае в Linux под «редактором по умолчанию» понимают `vi`/`vim`.

---

### 2.2. Как можно выйти из редактора Vim и сохранить изменения одной командой?

**Вопрос:** *Как можно выйти из редактора Vim и сохранить изменения одной командой?*

**Варианты ответов:**
- **`:wq`**
- `:q!`
- `:w!`
- `:qw`

**Правильный ответ:** `:wq`

**Разбор:**
- `:wq` — сохраняет изменения (write) и выходит (quit) одной командой.
- `:q!` — выходит без сохранения изменений (принудительный выход).
- `:w!` — принудительно сохраняет файл, но **не выходит** из редактора.
- `:qw` — такой команды не существует.

> **Важное примечание:** Альтернативный правильный вариант — `:x`. Он также сохраняет изменения и выходит, но отличается от `:wq` тем, что записывает файл только если были изменения. В некоторых тестах `:x` также считается верным.

---

### 2.3. Какая команда сделает резервную копию файла при его сохранении?

**Вопрос:** *Какая команда сделает резервную копию файла при его сохранении?*

**Варианты ответов:**
- **`nano myfile.txt -B`**
- `nano myfile.txt -s`
- `nano myfile.txt`
- `nano myfile.txt -b`

**Правильный ответ:** `nano myfile.txt -B`

**Разбор:**
- Флаг `-B` (или `--backup`) в Nano создаёт резервную копию файла при сохранении. Копия сохраняется в том же каталоге с символом `~` в конце имени (например, `myfile.txt~`).
- `nano myfile.txt -s` — флаг `-s` используется для указания программы проверки орфографии (spell checker).
- `nano myfile.txt` — обычный запуск Nano без резервного копирования.
- `nano myfile.txt -b` — в некоторых версиях Nano флаг `-b` также создаёт резервную копию, но он менее стандартизирован. Правильным и предпочтительным вариантом является `-B`.

## 3. Разбор типичных ошибок и спорных моментов

### 3.1. Почему в Ubuntu Vim не предустановлен, а Nano есть?

**Вопрос:** *Почему в некоторых дистрибутивах Linux (например, Ubuntu) Vim не предустановлен, а Nano есть?*

**Ответ:** Это особенность конкретной сборки. В Ubuntu Desktop выбрали `nano` для снижения порога входа для начинающих. Однако в большинстве серверных дистрибутивов (Debian, CentOS, RHEL) `vim` или `vi` присутствуют по умолчанию.

---

### 3.2. Обязательно ли владеть слепой печатью для работы в Vim?

**Вопрос:** *Обязательно ли владеть слепой печатью, чтобы эффективно использовать Vim?*

**Ответ:** Нет, но это значительно повышает скорость работы. Все основные команды навигации (`h j k l`) находятся в центре клавиатуры, что делает слепой набор очень удобным. Однако можно пользоваться и стрелками — скорость будет ниже, но редактирование останется возможным.

---

### 3.3. Чем отличается команда `:x` от `:wq` в Vim?

**Вопрос:** *Чем отличается команда `:x` от `:wq` в Vim?*

**Ответ:** Обе команды сохраняют изменения и выходят из редактора. Основное отличие: `:wq` всегда записывает файл на диск, а `:x` записывает файл только если были изменения. Это делает `:x` чуть более эффективным с точки зрения операций ввода-вывода.

---

### 3.4. Является ли `pico` современным редактором для Linux?

**Вопрос:** *Является ли `pico` актуальным редактором для Linux?*

**Ответ:** Нет. `pico` — устаревший редактор, который практически не используется в современных дистрибутивах. Его место занял `nano`, который является его форком и активно поддерживается.

---

### 3.5. Можно ли изменить редактор по умолчанию в системе?

**Вопрос:** *Можно ли изменить редактор по умолчанию в Linux?*

**Ответ:** Да. Для этого можно использовать переменную окружения `EDITOR` или команду `update-alternatives --config editor`. Например, `export EDITOR=nano` временно изменит редактор для текущей сессии.

## 4. Расширенный ИБ-контекст и инженерный FAQ

### 4.1. Векторы атак и уязвимости (Security Context)

- **Редактирование системных файлов:** Любое редактирование системных файлов (например, `/etc/ssh/sshd_config`) требует особой осторожности. Всегда делайте резервные копии перед изменениями.
- **Неправильный выход из Vim:** Если не сохранить изменения, данные могут быть потеряны. Команда `:q!` отбрасывает все изменения — используйте её только если уверены, что изменения не нужны.

### 4.2. Инженерный FAQ

- **Вопрос:** *Какая команда выходит из Vim с сохранением изменений?*  
  **Ответ:** `:wq` — сохраняет и выходит. Альтернатива — `:x`.

- **Вопрос:** *Как сделать резервную копию при сохранении в Nano?*  
  **Ответ:** Используйте флаг `-B`. Например, `nano -B myfile.txt`.

- **Вопрос:** *В чём разница между `nano -B` и `nano -b`?*  
  **Ответ:** `-B` — это стандартный флаг для резервного копирования. Флаг `-b` поддерживается не во всех версиях Nano, поэтому правильным считается `-B`.

- **Вопрос:** *Почему в Ubuntu Vim не предустановлен, а Nano есть?*  
  **Ответ:** Это особенность сборки Ubuntu. В большинстве других дистрибутивов по умолчанию присутствует `vi`/`vim`.

Модуль «Текстовые редакторы» охватывает два основных инструмента: Nano — для быстрых правок, Vim — для профессиональной работы в терминале. Понимание их команд, особенностей и сценариев использования является обязательным для системного администратора и разработчика.
