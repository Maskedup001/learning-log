# Тема 3.3: Vimtutor. Обучалка по редактору Vim

Изучение встроенного интерактивного учебника Vimtutor, который позволяет освоить базовые команды редактора Vim непосредственно в терминале. Рассматриваются запуск, установка, структура уроков, ключевые команды, языковая поддержка, а также практические проблемы и альтернативные ресурсы.

---

## 1. Vimtutor — Базовые свойства

- **Контекст/Уровень:** Системное администрирование / Изучение текстового редактора Vim в терминале.
- **Основное назначение:** Интерактивное обучение базовым командам Vim через практические упражнения прямо в редакторе.
- **Принцип работы:** `Vimtutor` — это текстовый файл, открываемый в Vim, с пошаговыми инструкциями и упражнениями. Пользователь выполняет команды, сразу видит результат и постепенно осваивает управление редактором.

### 1.1. Ключевые особенности

- **Интерактивность:** Обучение происходит непосредственно в редакторе через выполнение команд.
- **Доступность:** Работает в любом терминале, без графического интерфейса.
- **Языковая поддержка:** Доступен на нескольких языках, включая русский.
- **Бесплатно:** Входит в состав Vim, не требует дополнительных затрат.

### 1.2. Запуск Vimtutor

Для запуска учебника используется команда:

```bash
vimtutor
```

> **Важное примечание:** Если команда не найдена, значит, в системе установлена минимальная версия Vim. Требуется установить расширенный пакет (см. раздел 2).

## 2. Архитектура / Анатомия процесса по шагам

### 2.1. Установка Vimtutor (если отсутствует)

Для установки полнофункциональной версии Vim выполните:

```bash
sudo apt install vim
```

Эта команда устанавливает Vim с поддержкой дополнительных возможностей (подсветка синтаксиса, информационная строка, расширенные настройки).

**Опционально:** Для поддержки всех языковых файлов и дополнительных runtime-компонентов:

```bash
sudo apt install vim-runtime -y
```

Ключ `-y` автоматически подтверждает установку, избавляя от необходимости вручную вводить `Y`.

> **Пояснение:** `vim-runtime` содержит файлы, необходимые для работы Vim с разными языками, включая учебные файлы `vimtutor`, подсветку синтаксиса, плагины и справку. Без него некоторые функции могут быть недоступны (например, `vimtutor ru` может не работать).

| Шаг | Действие | Результат |
| :--- | :--- | :--- |
| 1 | `sudo apt install vim` | Установка полнофункционального Vim |
| 2 | (опционально) `sudo apt install vim-runtime -y` | Установка дополнительных файлов |
| 3 | `vimtutor` | Запуск учебника |
*Таб. 1. Пошаговый алгоритм установки и запуска Vimtutor*

### 2.2. Запуск с выбором языка

Vimtutor поддерживает несколько языков. Для запуска на нужном языке используется команда с языковым кодом:

| Язык | Команда |

| Немецкий | `vimtutor de` |
| Испанский | `vimtutor es` |

### 2.3. Структура обучения

Vimtutor состоит из **7 уроков**, каждый занимает примерно половину экрана. Темы включают:

- Навигация курсором (клавиши `h`, `j`, `k`, `l`)
- Выход из редактора (`:q!`)
- Режимы работы Vim
- Удаление, копирование и вставка текста
- Поиск и замена
- Выполнение команд

> **Пояснение:** каждый урок — это не просто текст, а **интерактивное упражнение**: вы читаете инструкцию, тут же выполняете команду и сразу видите результат. Это принципиально отличается от просмотра видео или чтения книги.

### 2.4. Выход из Vimtutor

Как и в обычном Vim, для выхода используется команда в режиме команд:

```vim
:q!
```

## 3. Разбор сложных инженерных ситуаций, граничных кейсов и аномалий

1. **Отсутствие `vimtutor` в системе:** Если команда `vimtutor` не найдена, это означает, что установлена минимальная версия Vim (`vim-tiny`). Решение — установить полнофункциональную версию (после установки `vimtutor` становится доступен):
  ```bash
  sudo apt install vim
  ```

2. **Ошибка `E484: Can't open file /usr/share/nvim/runtime/tutor/tutor.vim`:** Эта ошибка возникает, если используется `neovim`, а файл `tutor.vim` отсутствует. Решение:
  - Проверить наличие каталога `/usr/share/nvim/runtime/tutor/`.
  - Если каталог есть, но файла нет — скачать или создать его.
  - Если используется `vim`, можно открыть русскую версию напрямую:
  
    ```bash
    vim /usr/share/vim/vim90/tutor/tutor.ru.utf-8
    ```

> **Пояснение:** Эта ошибка возникает потому, что `neovim` использует другой каталог для учебных файлов, чем `vim`. Вместо `/usr/share/vim/` он ищет в `/usr/share/nvim/`. Поэтому если на системе установлены и `vim`, и `neovim`, команда `vimtutor` может запускать `neovim` вместо `vim`, и файл не находится.

3. **Пустой экран с тильдами (`~`) после запуска:** Это происходит, если Vim открыл пустой файл или не загрузил учебник. В таком случае проверьте правильность команды запуска и наличие установленных `vim-runtime` файлов.

4. **Проблемы с русским языком при редактировании:** При работе с кириллицей в Vim сложно переключаться между режимами ввода и командами, так как команды требуют латиницы. Рекомендуется:
  - Переключать раскладку перед вводом команд.
  - Использовать `Ctrl + [` вместо `Esc` для выхода из режимов.
  - Переназначить `CapsLock` на `Ctrl` для удобства.

5. **Не работает ввод на кириллице:** Убедитесь, что в терминале выбрана правильная кодировка (UTF-8) и установлены локали.

6. **Если `vimtutor ru` показывает «крякозябры» (нечитаемые символы):** Установите и настройте локали и выберите `ru_RU.UTF-8`:

  ```bash
  sudo apt install locales
  sudo dpkg-reconfigure locales
  ```

## 4. Лимиты, оптимизация и масштабирование

- **Ограничение по объёму:** Vimtutor содержит 7 уроков, что достаточно для освоения базовых команд, но для глубокого изучения Vim требуется дополнительная литература или встроенная справка (`:help`).
- **Ресурсные ограничения:** Vimtutor не потребляет значительных ресурсов, так как работает в терминале и является обычным текстовым файлом.
- **Масштабирование:** Для освоения Vim в продакшене рекомендуется пройти `vimtutor` несколько раз, а затем перейти к `:help user-manual` или специализированным книгам.

## 6. Влияние на смежные системы и компоненты

### 6.1. Зависимости
- **Vim:** Для работы `vimtutor` требуется установленный Vim (желательно полнофункциональная версия, не `vim-tiny`).
- **Runtime-файлы:** Для поддержки языков и подсветки синтаксиса могут потребоваться пакеты `vim-runtime` или `vim-data`.
- **Локали:** Для корректного отображения русского текста необходимо настроить локали (`locale-gen ru_RU.UTF-8`, `update-locale`).

### 6.2. Влияние на производительность
- `vimtutor` не оказывает заметного влияния на производительность системы, так как является небольшим текстовым файлом.
- **Эффективность обучения:** При освоении Vim через `vimtutor` пользователь быстрее привыкает к клавиатурным командам, что впоследствии ускоряет работу с текстом.

### 6.3. Влияние на безопасность
- **Запуск `vimtutor` с правами `sudo` не требуется.** Это обычный пользовательский процесс.
- **Учебник не изменяет системные файлы** — все изменения происходят только в копии учебного файла.

## 7. Расширенный ИБ-контекст и инженерный FAQ

### 7.1. Векторы атак и уязвимости (Security Context)

- **Использование `vimtutor` не создаёт угроз безопасности**, так как учебник не содержит исполняемого кода и не требует специальных привилегий.
- **Потенциальная угроза:** Если пользователь неправильно настроит `vimrc` или установит плагины из ненадёжных источников после обучения, это может привести к компрометации системы. Рекомендуется изучать Vim на изолированной среде или виртуальной машине.

### 7.2. Инженерный FAQ (На основе разбора дискуссий)

- **Вопрос:** *Как запустить Vimtutor на русском языке?*  
  **Технический ответ:** Используйте команду `vimtutor ru`. Если команда не работает, убедитесь, что установлен полноценный Vim (`sudo apt install vim`). Если символы отображаются некорректно, настройте локали (`sudo dpkg-reconfigure locales`).

- **Вопрос:** *Что делать, если `vimtutor` выдаёт ошибку `E484: Can't open file...`?*  
  **Технический ответ:** Это означает, что файлы учебника отсутствуют. Решение: установить пакет `vim-runtime` или использовать команду `vim /usr/share/vim/vim90/tutor/tutor.ru.utf-8` для непосредственного открытия русской версии учебника.

- **Вопрос:** *Можно ли редактировать текст на русском языке в Vimtutor?*  
  **Технический ответ:** Да, но при этом сложно переключаться между режимами, так как команды требуют латиницы. Рекомендуется переключать раскладку перед вводом команд или использовать `Ctrl + [` вместо `Esc`.

- **Вопрос:** *Существуют ли другие интерактивные игры для изучения Vim?*  
  **Технический ответ:** Да, например: [Vim Adventures](https://vim-adventures.com/), [VimMaster](https://renzorlive.github.io/vimmaster/). Они помогают закрепить навыки в игровой форме, но не заменяют работу в реальном терминале.

- **Вопрос:** *Почему после запуска `vimtutor` я вижу только тильды (`~`)?*  
  **Технический ответ:** Это значит, что Vim открыл пустой файл или не загрузил учебник. Проверьте правильность установки пакетов и наличие файла `/usr/share/vim/vim90/tutor/tutor.ru.utf-8`. Попробуйте переустановить Vim или вручную открыть файл учебника.

- **Вопрос:** *Нужно ли устанавливать `vim-runtime` для работы `vimtutor`?*  
  **Технический ответ:** Обычно достаточно установить `vim`, но в некоторых системах требуется `vim-runtime` для поддержки всех языков и дополнительных файлов.

- **Вопрос:** *Что делать, если `vimtutor ru` показывает кракозябры вместо русского текста?*
  **Технический ответ:** Установите и настройте локали (`sudo apt install locales`, затем `sudo dpkg-reconfigure locales` и выберите `ru_RU.UTF-8`).

- **Вопрос:** *В чём разница между `vimtutor` в `vim` и `neovim`?*  
  **Технический ответ:** `vimtutor` — это команда, которая запускается вместе с Vim. В `neovim` она может не работать напрямую из-за разных путей к файлам. Если вы используете `neovim`, лучше запускать учебник через `vim` (если он установлен) или вручную открывать файл: `vim /usr/share/vim/vim90/tutor/tutor.ru.utf-8`.

## 9. Содержание уроков Vimtutor (полный разбор)

Ниже приведено полное содержание всех 7 уроков Vimtutor с командами, примерами и примечаниями.

### 9.1. Урок 1: Основы навигации, выхода и редактирования

**Урок 1.1. Перемещение курсора**

Для перемещения курсора используются клавиши `h`, `j`, `k`, `l`:

```
             ^
             k
       < h       l >
             j
             v
```

| Клавиша | Действие |
| :--- | :--- |
| `h` | Влево |
| `j` | Вниз |
| `k` | Вверх |
| `l` | Вправо |
*Таб. 5. Клавиши навигации в Vimtutor*

> **Замечание:** Если вы не уверены в том, что набираете, нажмите `<ESC>` для перехода в обычный режим (Normal mode) и повторите команду. Стрелки тоже работают, но клавиши `hjkl` позволяют перемещаться быстрее.

**Урок 1.2. Завершение работы с Vim**

Для выхода из Vim без сохранения изменений:

1. Нажмите `<ESC>` (убедитесь, что вы в обычном режиме).
2. Наберите `:q!` и нажмите `<ENTER>`.

**Урок 1.3. Удаление символа**

Для удаления символа под курсором в обычном режиме нажмите `x`.

**Пример:** Исправьте строку:

```
---> От тттопота копытт пппыль ппо ппполю леттитт.
```

Удалите лишние символы клавишей `x`.

**Урок 1.4. Вставка текста**

Для вставки текста перед курсором в обычном режиме нажмите `i`, введите текст, затем нажмите `<ESC>`.

**Пример:** Исправьте строку:

```
---> Часть текста в строке бесследно .
---> Часть текста в этой строке бесследно пропала.
```

**Урок 1.5. Добавление текста**

Для добавления текста в конец строки нажмите `A`, введите текст, затем нажмите `<ESC>`.

**Пример:** Исправьте строки:

```
---> Часть текста в этой строке бессле
---> Часть текста в этой строке бесследно пропала.
---> Здесь также не достаёт час
---> Здесь также не достаёт части текста.
```

**Урок 1.6. Редактирование файла**

Для сохранения файла и выхода из Vim используйте `:wq`.

**Алгоритм:**
1. Выйдите из Vim (как в уроке 1.2).
2. Запустите Vim с новым файлом: `vim tutor`.
3. Вставляйте и удаляйте текст (как в предыдущих уроках).
4. Сохраните и выйдите: `:wq`.

**Резюме Урока 1:**

- Курсор перемещается клавишами `h`, `j`, `k`, `l` (или стрелками).
- Запуск Vim: `vim ИМЯ_ФАЙЛА`.
- Выход без сохранения: `:q!`.
- Выход с сохранением: `:wq`.
- Удаление символа: `x`.
- Вставка перед курсором: `i`.
- Добавление после курсора: `a`.

### 9.2. Урок 2: Команды удаления и объекты

**Урок 2.1. Удаление слова**

Для удаления слова от курсора до конца слова наберите `dw`.

**Пример:** Исправьте строку:

```
---> Несколько слов рафинад в этом предложении автокран излишни.
```

Удалите лишние слова (`рафинад`, `автокран`) с помощью `dw`.

**Урок 2.2. Удаление до конца строки**

Для удаления текста от курсора до конца строки наберите `d$`.

**Пример:** Исправьте строку:

```
---> Кто-то набрал окончание этой строки дважды. окончание этой строки дважды.
```

Удалите второе повторение с помощью `d$`.

**Урок 2.3. Команды и объекты**

Формат команды удаления: `d объект`.

| Объект | Действие |
| :--- | :--- |
| `w` | От курсора до конца слова (включая пробел) |
| `e` | От курсора до конца слова (без пробела) |
| `$` | От курсора до конца строки |
| `^` | От курсора до начала строки |
*Таб. 6. Объекты для команд удаления*

**Урок 2.4. Использование счётчика для перемещения**

Ввод числа перед оператором перемещения повторяет его заданное количество раз.

**Примеры:**
- `2w` — перейти к началу второго слова.
- `3e` — перейти к концу третьего слова.
- `0` — перейти к началу строки.

**Урок 2.5. Использование счётчика для удаления**

Формат: `d число объект`.

**Пример:** `d2w` — удалить два слова.

**Урок 2.6. Операции со строками**

- `dd` — удалить текущую строку.
- `2dd` — удалить две строки.

**Урок 2.7. Команда отмены**

| Команда | Действие |
| :--- | :--- |
| `u` | Отменить последнее действие |
| `U` | Отменить все изменения в строке |
| `Ctrl + R` | Повторить отменённое действие (откат отката) |
*Таб. 7. Команды отмены и повтора*

**Резюме Урока 2:**

- `dw` — удалить до конца слова.
- `d$` — удалить до конца строки.
- `dd` — удалить строку.
- Формат: `[число] команда объект`.
- `0` — перейти в начало строки.
- `u` — отмена, `U` — отмена в строке, `Ctrl + R` — повтор.

### 9.3. Урок 3: Вставка, замена и изменение

**Урок 3.1. Вставка последнего удалённого текста**

`p` — вставить последний удалённый текст после курсора (если удалена строка — ниже курсора).

**Пример:** Переставьте строки в правильном порядке:

```
---> г) И лучше выдумать не мог.
---> б) Когда не в шутку занемог,
---> в) Он уважать себя заставил
---> а) Мой дядя самых честных правил
```

**Урок 3.2. Замена символа**

`r` + символ — заменить символ под курсором на указанный.

**Пример:** Исправьте ошибки в строке:

```
---> В момегт набтра этой чтроки кое0кто с трудом попвдал по клваишам!
---> В момент набора этой строки кое-кто с трудом попадал по клавишам!
```

**Урок 3.3. Команда изменения**

`ce` — удалить до конца слова и перейти в режим вставки для исправления.

**Пример:** Исправьте строку:

```
---> Несколько сола в эьгц строке тпгшцбь редалзкуюиесвх.
---> Несколько слов в этой строке требуют редактирования.
```

**Урок 3.4. Продолжаем изменять с `c`**

Команда `c` работает с теми же объектами, что и `d`.

**Формат:** `[число] c объект` или `c [число] объект`.

**Пример:** `c$` — удалить до конца строки и перейти в режим вставки.

**Резюме Урока 3:**

- `p` — вставить удалённый текст.
- `r` + символ — заменить один символ.
- `ce` — изменить до конца слова.
- `c$` — изменить до конца строки.

---

### 9.4. Урок 4: Информация о файле, поиск и замена

**Урок 4.1. Информация о файле и расположении**

| Команда | Действие |
| :--- | :--- |
| `Ctrl + G` | Показать имя файла и номер строки |
| `G` (`Shift + G`) | Перейти в конец файла |
| `номер + G` | Перейти к строке с указанным номером |
| `gg` | Перейти в начало файла |
*Таб. 8. Команды для работы с файлом*

**Урок 4.2. Команда поиска**

- `/строка` — поиск вперёд.
- `?строка` — поиск назад.
- `n` — перейти к следующему совпадению.
- `N` (`Shift + N`) — перейти к предыдущему совпадению.
- `Ctrl + O` — вернуться к предыдущей позиции.
- `Ctrl + I` — перейти вперёд по истории переходов.

**Пример:** Поиск слова `ошшшибка`:

```
/ошшшибка <ENTER>
```

**Урок 4.3. Поиск парных скобок**

`%` — найти парную скобку для `(`, `)`, `[`, `]`, `{`, `}`.

**Пример:** Наведите курсор на любую скобку в строке и нажмите `%`:

```
---> Это ( строка, содержащая такие (, такие [ ] и такие { } скобки. ))
```

**Урок 4.4. Замена текста**

| Команда | Действие |
| :--- | :--- |
| `:s/было/стало` | Заменить первое вхождение в строке |
| `:s/было/стало/g` | Заменить все вхождения в строке |
| `:#,#s/было/стало/g` | Заменить между строками # и # |
| `:%s/было/стало/g` | Заменить все вхождения во всём файле |
| `:%s/было/стало/gc` | Заменить с запросом подтверждения |
*Таб. 9. Команды замены текста*

**Пример:** Замените `уводю` на `увожу`:

```
:s/уводю/увожу/g
```

**Резюме Урока 4:**

- `Ctrl + G` — информация о файле.
- `G` — конец файла, `gg` — начало файла.
- `/` — поиск вперёд, `?` — поиск назад, `n`/`N` — навигация по результатам.
- `%` — поиск парной скобки.
- `:s/было/стало/g` — замена текста.

---

### 9.5. Урок 5: Внешние команды и работа с файлами

**Урок 5.1. Выполнение внешних команд**

`:!команда` — выполнить внешнюю команду.

**Примеры:**
- `:!ls` — показать список файлов в Linux.
- `:!dir` — показать список файлов в Windows.

**Урок 5.2. Запись файла**

`:w ИМЯ_ФАЙЛА` — сохранить текущий файл под новым именем.

**Пример:**

```
:w TEST
```

**Урок 5.3. Выборочное сохранение**

1. Нажмите `v` (визуальный режим).
2. Выделите нужные строки.
3. Нажмите `:` и введите `w ИМЯ_ФАЙЛА`.

**Пример:** `:'<,'>w TEST`

**Урок 5.4. Чтение и объединение файлов**

`:r ИМЯ_ФАЙЛА` — вставить содержимое файла ниже курсора.

**Пример:**

```
:r TEST
```

**Резюме Урока 5:**

- `:!команда` — выполнить внешнюю команду.
- `:w ИМЯ_ФАЙЛА` — сохранить файл.
- `v` + `:w ИМЯ_ФАЙЛА` — сохранить выделенные строки.
- `:r ИМЯ_ФАЙЛА` — вставить содержимое файла.

---

### 9.6. Урок 6: Создание строк, вставка и параметры

**Урок 6.1. Создание строк**

- `o` — создать пустую строку ниже курсора и перейти в режим вставки.
- `O` (`Shift + O`) — создать пустую строку выше курсора и перейти в режим вставки.

**Урок 6.2. Вставка после курсора**

- `a` — вставить текст после курсора.
- `A` (`Shift + A`) — вставить текст в конец строки.

**Урок 6.3. Режим замены**

`R` (`Shift + R`) — перейти в режим замены (каждый введённый символ удаляет существующий).

**Урок 6.4. Копирование и вставка**

1. `v` — визуальный режим, выделите текст.
2. `y` — копировать (yank).
3. `p` — вставить скопированный текст.

> **Замечание:** `yw` — скопировать одно слово.

**Урок 6.5. Установка параметров**

| Команда | Действие |
| :--- | :--- |
| `:set ic` | Игнорировать регистр при поиске |
| `:set noic` | Не игнорировать регистр |
| `:set hls` | Подсветка совпадений при поиске |
| `:set is` | Отображение частичных совпадений |
| `:nohlsearch` | Отключить подсветку совпадений |
*Таб. 10. Параметры поиска и подсветки*

**Пример:** Включите игнорирование регистра и подсветку:

```
:set ic hls is
```

**Резюме Урока 6:**

- `o` / `O` — создать строку ниже/выше.
- `a` — вставить после курсора, `A` — в конец строки.
- `R` — режим замены.
- `y` — копировать, `p` — вставить.
- `:set ic` — игнорировать регистр.
- `:set hls is` — подсветка и частичный поиск.

### 9.7. Урок 7: Справка, стартовый сценарий и дополнение

**Урок 7.1. Встроенная справка**

| Действие | Команда |
| :--- | :--- |
| Открыть справку | `:help` или `<F1>` или `<HELP>` |
| Справка по команде | `:help w` |
| Переход между окнами | `Ctrl + W` + `Ctrl + W` |
| Закрыть справку | `:q` |
*Таб. 11. Команды для работы со справкой*

**Урок 7.2. Создание стартового сценария (`vimrc`)**

1. Отредактируйте новый файл:
   - Для Unix: `:e ~/.vimrc`
   - Для Windows: `:e ~/_vimrc`
2. Прочитайте пример: `:r $VIMRUNTIME/vimrc_example.vim`
3. Сохраните: `:w`

**Урок 7.3. Дополнение команд**

- `Ctrl + D` — показать возможные дополнения.
- `<TAB>` — дополнить команду или имя файла.

**Резюме Урока 7:**

- `:help` — открыть справку.
- `Ctrl + W` + `Ctrl + W` — переключить окна.
- Создайте `vimrc` для сохранения настроек.
- `Ctrl + D` и `<TAB>` — дополнение команд.

## 10. Дополнительные возможности после установки Vim

После установки расширенного пакета `vim` сам редактор становится более дружественным:

- Появляется информационная строка внизу окна.
- Включается подсветка синтаксиса (для файлов с кодом).
- Добавляются дополнительные настройки по умолчанию.
