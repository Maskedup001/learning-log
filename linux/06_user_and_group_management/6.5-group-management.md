# Тема 6.5: Управление группами

В данной теме рассматриваются команды для управления группами в Linux: создание (`groupadd`, `addgroup`), просмотр информации (`cat /etc/group`, `groups`, `id`), добавление и удаление пользователей из групп (`usermod`, `deluser`, `gpasswd`) и удаление групп (`groupdel`). Разбираются ключевые понятия: GID, основная и дополнительные группы, а также отличия между низкоуровневыми утилитами и скриптами-обёртками.

---

## 1. Создание групп — `groupadd`

Команда `groupadd` (group add) используется для создания новых групп в Linux. Она присутствует во всех дистрибутивах и является низкоуровневой утилитой.

- **Контекст/Уровень:** Системное администрирование / Управление пользователями и группами.
- **Основное назначение:** Создание новых групп в системе.
- **Принцип работы:** низкоуровневая утилита, которая добавляет запись в файл `/etc/group`. Она присутствует во всех дистрибутивах Linux.

### 1.1. Базовый синтаксис

```bash
sudo groupadd groupname
```

Для создания группы требуются права суперпользователя (`sudo`).

### 1.2. Основные ключи `groupadd`

| Ключ | Описание |
| :--- | :--- |
| `-g GID` | Задать числовой идентификатор группы вручную. |
| `-r` | Создать системную группу (с GID в диапазоне 1–999). |
| `-f` | Принудительное создание (если группа существует, вернуть успех без ошибки). |
*Таб. 1. Основные ключи команды `groupadd`.*

### 1.3. Пример

```bash
sudo groupadd remoteworkers
```

---

## 2. Альтернатива — `addgroup`

Команда `addgroup` — это скрипт-обёртка, которая упрощает создание групп. Она не входит во все дистрибутивы (отсутствует, например, в минимальных установках), но присутствует в Ubuntu и Debian-подобных системах.

### 2.1. Сравнение `groupadd` и `addgroup`

| Характеристика | `groupadd` | `addgroup` |
| :--- | :--- | :--- |
| Тип | Бинарный файл | Скрипт-обёртка |
| Доступность | Во всех дистрибутивах | Не во всех (Ubuntu/Debian) |
| Интерактивность | Нет | Может быть интерактивной |
*Таб. 2. Сравнение `groupadd` и `addgroup`.*

### 2.2. Морфологическое правило

В мире Linux утилиты для управления пользователями и группами часто имеют названия, где **существительное + глагол**:

- `groupadd` — group + add (создать группу)
- `groupdel` — group + del (удалить группу)
- `groupmod` — group + mod (изменить группу)
- `useradd`, `userdel`, `usermod` — по тому же принципу

Скрипты-обёртки (`adduser`, `addgroup`) имеют **обратный порядок**: глагол + существительное.

## 3. Просмотр информации о группах

### 3.1. Файл `/etc/group`

```bash
cat /etc/group          # весь файл
tail /etc/group         # последние 10 строк
grep remoteworkers /etc/group   # поиск конкретной группы
```

**Формат строки в `/etc/group` (разделитель — двоеточие `:`):**

| Поле | Описание |
| :--- | :--- |
| 1 | Название группы |
| 2 | Пароль группы (обычно `x` или пусто) |
| 3 | `GID` (Group ID) — числовой идентификатор |
| 4 | Список пользователей, входящих в группу (через запятую) |
*Таб. 3. Поля файла `/etc/group`.*

### 3.2. Просмотр групп пользователя

```bash
groups username         # группы указанного пользователя
groups                  # группы текущего пользователя
id username             # подробная информация с UID, GID и группами
```

## 4. Добавление пользователей в группу — `usermod`

Для добавления существующего пользователя в группу используется команда `usermod` с ключами `-a` и `-G`.

### 4.1. Синтаксис

```bash
sudo usermod -a -G groupname username
```

- `-a` (append) — добавить к существующим дополнительным группам (без этого ключа пользователь будет удалён из всех других дополнительных групп).
- `-G` (groups) — указать список дополнительных групп (можно указать несколько через запятую без пробелов).

> **Важно:** Не путайте `-g` и `-G`.  
> - `-g` меняет **основную** группу пользователя.  
> - `-G` (вместе с `-a`) добавляет пользователя в **дополнительные** группы.  
> Использование `-G` без `-a` перезаписывает все дополнительные группы.

### 4.2. Примеры

```bash
# Добавление одного пользователя в группу
sudo usermod -a -G remoteworkers salesguy

# Добавление нескольких пользователей
sudo usermod -a -G remoteworkers outgoinghr
sudo usermod -a -G remoteworkers itguy

# Добавление пользователя в несколько групп одновременно
sudo usermod -a -G sudo,docker,remoteworkers username
```

### 4.3. Проверка после добавления

```bash
groups salesguy
grep remoteworkers /etc/group
```

> **Напоминание:** `useradd` создаёт нового пользователя, а `usermod` изменяет уже существующего.

> **Альтернативный способ: `groupmems`**  
> В некоторых дистрибутивах (например, в Debian/Ubuntu) для управления членами группы можно использовать команду `groupmems`. Она позволяет добавлять и удалять пользователей из группы без использования `usermod`.
>
> **Синтаксис для добавления пользователя в группу:**
> ```bash
> sudo groupmems -g groupname --add username
> ```
> - `-g` — указывает имя группы, в которую нужно добавить пользователя.
> - `--add` — действие: добавить пользователя.
> - `username` — имя пользователя, которого добавляем.
>
> **Пример:**
> ```bash
> sudo groupmems -g office_manager --add tony
> groups tony
> ```
>
> **Важное замечание:** В некоторых реализациях `groupmems` может запрашивать пароль даже при выполнении от имени `root`. Это особенность конкретной версии утилиты и не является ошибкой.

## 5. Удаление пользователей из группы — `deluser` или `gpasswd`

### 5.1. С помощью `deluser`

```bash
sudo deluser username groupname
```

**Пример:**
```bash
sudo deluser salesguy remoteworkers
```

### 5.2. С помощью `gpasswd`

```bash
sudo gpasswd -d username groupname
```

Ключ `-d` (delete) удаляет пользователя из указанной группы.

**Пример:**
```bash
sudo gpasswd -d salesguy remoteworkers
```

> **Добавление через `gpasswd -a`:**  
> Команда `gpasswd` также позволяет **добавлять** пользователя в группу. Для этого используется ключ `-a` (add).  
> 
> ```bash
> sudo gpasswd -a username groupname
> ```
> 
> **Пример:**  
> ```bash
> sudo gpasswd -a salesguy remoteworkers
> ```
> 
> **Важное отличие от `usermod -a -G`:**  
> В `usermod` сначала идёт группа, потом пользователь (`usermod -a -G group user`). В `gpasswd` — сначала пользователь, потом группа (`gpasswd -a user group`). Это легко перепутать, поэтому всегда проверяйте синтаксис.

### 5.3. Чем `usermod` отличается от `groupmems`?

Обе команды могут добавлять пользователя в группу, но у них разный подход и область применения.

| Характеристика       | `usermod -a -G`                                      | `groupmems`                                              |
| :------------------- | :--------------------------------------------------- | :------------------------------------------------------- |
| **Тип**              | Универсальная утилита для изменения пользователя     | Специализированная утилита для управления членами группы |
| **Доступность**      | Во всех дистрибутивах                                | Не во всех (в основном Debian/Ubuntu)                    |
| **Синтаксис**        | `usermod -a -G group user`                           | `groupmems -g group --add user`                          |
| **Что делает**       | Добавляет пользователя в дополнительные группы       | Добавляет пользователя в группу (через /etc/group)       |
| **Основное отличие** | Работает с пользователем («изменить пользователя»)   | Работает с группой («изменить группу»)                   |
| **Особенность**      | Всегда используй `-a`, иначе потеряешь другие группы | Может запрашивать пароль даже от root                    |
*Таб. 4. Различие между `usermod` и  `groupmems`.*

## 6. Удаление групп — `groupdel`

Команда `groupdel` (group delete) удаляет существующую группу.

### 6.1. Синтаксис

```bash
sudo groupdel groupname
```

### 6.2. Важные ограничения

- Нельзя удалить группу, если она является **основной (primary)** для какого-либо пользователя.
- Перед удалением группы необходимо либо удалить пользователей, у которых эта группа является основной, либо сменить им основную группу.

### 6.3. Пример

```bash
sudo groupdel remoteworkers
```

### 6.4. Проверка после удаления

```bash
grep remoteworkers /etc/group   # ничего не найдено
groups salesguy                 # группа отсутствует в списке
```

## 7. Другие команды для работы с группами

| Команда | Назначение |
| :--- | :--- |
| `groupmod -n newname oldname` | Переименовать группу. |
| `groupmod -g newGID groupname` | Изменить GID группы. |
| `gpasswd groupname` | Установить пароль для группы. |
| `gpasswd -A user groupname` | Назначить администратора группы. |
| `newgrp groupname` | Временно переключить основную группу текущего пользователя. |
*Таб. 5. Дополнительные команды для работы с группами.*

> **Примечание про `newgrp`:**  
> Команда `newgrp` временно меняет основную группу текущего пользователя на указанную.  
> После выхода из сессии или завершения терминала группа возвращается к исходной.  
> Это полезно, когда нужно временно получить доступ к файлам, принадлежащим другой группе.

## 8. Практические примеры

### 8.1. Создание группы и добавление пользователей

```bash
# Создать группу
sudo groupadd developers

# Добавить пользователей в группу
sudo usermod -a -G developers alice
sudo usermod -a -G developers bob

# Проверить
grep developers /etc/group
# developers:x:1006:alice,bob
```

### 8.2. Удаление пользователя из группы

```bash
sudo deluser alice developers
# или
sudo gpasswd -d alice developers
```

### 8.3. Удаление группы

```bash
# Убедиться, что группа не является основной ни для кого
sudo groupdel developers
```

### 8.4. Создание системной группы

```bash
sudo groupadd -r systemservice
```

Системные группы используются для запуска служб и имеют GID в диапазоне 1–999.

## 9. Разбор сложных ситуаций и типичных вопросов

### 9.1. Почему используется `grep`, если её ещё не проходили?

**Вопрос:** *В этом разделе используется команда `grep`, хотя её не разбирали ранее. Почему?*

**Ответ:** `grep` применяется здесь только для поиска строки в файле (`grep слово файл`) — это простой и интуитивно понятный способ проверить, есть ли группа в `/etc/group`. В следующих темах `grep` будет рассмотрена подробнее.

### 9.2. Как переключить основную группу пользователя?

**Вопрос:** *Как изменить основную группу пользователя?*

**Ответ:** Для изменения основной группы используется `usermod` с ключом `-g`. Например:

```bash
sudo usermod -g newprimarygroup username
```

### 9.3. Что делать, если группа не удаляется?

**Вопрос:** *Почему `sudo groupdel groupname` выдаёт ошибку?*

**Ответ:** Это происходит, если группа является основной (primary) для какого-либо пользователя. Проверьте это через `grep groupname /etc/passwd` и либо смените пользователю основную группу, либо удалите пользователя.

## 10. Лимиты, оптимизация и масштабирование

- **Основная vs дополнительные группы:** У каждого пользователя есть ровно одна основная группа (указана в `/etc/passwd`), но может быть множество дополнительных (в `/etc/group`).
- **Безопасность добавления:** При добавлении в дополнительные группы всегда используйте `-a`, чтобы не потерять существующие членства.
- **Удаление групп:** Нельзя удалить группу, если она является основной для какого-либо пользователя.

## 11. Расширенный ИБ-контекст и инженерный FAQ

### 1. Векторы атак и уязвимости (Security Context)

- **Потеря прав:** Неправильное использование `usermod -G` (без `-a`) может привести к потере всех дополнительных групп пользователя, что ограничит его доступ к системе.
- **Удаление основной группы:** Случайное удаление группы, которая является основной для пользователя, может привести к невозможности входа в систему.

### 2. Инженерный FAQ

- **Вопрос:** *Как добавить пользователя в группу без `usermod`?*  
  **Ответ:** Можно использовать `gpasswd -a username groupname` или `groupmems -g groupname --add username`.

- **Вопрос:** *Как посмотреть список всех групп в системе?*  
  **Ответ:** Используйте `cat /etc/group` или `getent group`.

- **Вопрос:** *Как создать системную группу?*  
  **Ответ:** Используйте `sudo groupadd -r groupname`. GID будет автоматически назначен в диапазоне 1–999.

## 12. Итоговая шпаргалка по командам

| Действие | Команда |
| :--- | :--- |
| Создать группу | `sudo groupadd groupname` |
| Добавить пользователя в группу | `sudo usermod -a -G groupname username` |
| Удалить пользователя из группы | `sudo deluser username groupname` или `sudo gpasswd -d username groupname` |
| Удалить группу | `sudo groupdel groupname` |
| Просмотреть все группы | `cat /etc/group` |
| Просмотреть группы пользователя | `groups username` |
*Таб. 6. Итоговая шпаргалка по командам.*

### Ключевые понятия:

- **GID** — числовой идентификатор группы.
- **Основная группа (primary group)** — группа, указанная в `/etc/passwd` в поле GID. У каждого пользователя есть ровно одна основная группа.
- **Дополнительные группы (secondary groups)** — группы, в которые пользователь добавлен через `/etc/group`.
- При добавлении в дополнительные группы **всегда используйте `-a`**, чтобы не потерять существующие членства.
- Группу **нельзя удалить**, если она является основной для какого-либо пользователя.
