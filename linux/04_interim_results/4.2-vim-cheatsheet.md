# Тема 4.2: Шпаргалка по редактору Vim (полный справочник горячих клавиш)

В данной теме представлен структурированный справочник горячих клавиш текстового редактора Vim, охватывающий навигацию, редактирование, операторы, визуальные режимы, буфер обмена, поиск, замену, работу с файлами и окнами, а также продвинутые техники (поиск символов, метки, текстовые объекты). Все сочетания разбиты по функциональным группам и дополнены пояснениями. В конце приведён разбор типичных вопросов и практических лайфхаков.

---

## 1. Vim — Базовые свойства (в контексте горячих клавиш)

- **Контекст/Уровень:** Системное администрирование / Работа с текстовыми файлами в терминале.
- **Основное назначение:** Ускорение и повышение эффективности редактирования текста в терминале без использования графического интерфейса.
- **Принцип работы:** Vim (Vi Improved) — текстовый редактор, работающий в терминале. Его ключевая особенность — разделение режимов: **нормальный** (для навигации и команд), **режим вставки** (для ввода текста), **визуальный** (для выделения) и **командный** (для сохранения, выхода и настроек). Горячие клавиши позволяют выполнять сложные операции с текстом без использования мыши, что даёт огромную скорость после освоения.

> **Обозначение:** Команды в командном режиме вводятся после нажатия `:` (двоеточие).

## 2. Полный список горячих клавиш (по функциональным группам)

### 2.1. Перемещение курсора (нормальный / визуальный режимы)

| Сочетание клавиш | Действие |
| :--- | :--- |
| `h` / `j` / `k` / `l` | Влево / Вниз / Вверх / Вправо (аналог стрелок). |
| `w` / `b` | На слово вперёд / На слово назад (по границам слов: буквы, цифры, подчёркивания). |
| `W` / `B` | На слово вперёд / назад (разделённое только пробелами, не учитывает знаки препинания). |
| `e` / `ge` | К концу текущего слова / К концу предыдущего слова. |
| `0` / `$` | В начало строки / В конец строки. |
| `^` | К первому непустому символу строки (аналог `0w`). |
| `gg` | В начало файла. |
| `G` | В конец файла. |
| `:[число]` (Enter) | Перейти к указанной строке (например, `:42` перейдёт на строку 42). |
| `Ctrl + d` | Переместиться вниз на полстраницы. |
| `Ctrl + u` | Переместиться вверх на полстраницы. |
| `Ctrl + e` / `Ctrl + y` | Прокрутить экран вниз / вверх на одну строку (без перемещения курсора). |
| `}` / `{` | Вперёд на абзац (до следующей пустой строки) / Назад на абзац (до предыдущей пустой строки). |
*Таб. 1. Горячие клавиши для перемещения курсора.*

> **Пояснение про `W` и `B`:** Обычные `w` и `b` останавливаются на границах слов (например, `end-of-word`). `W` и `B` игнорируют знаки препинания и считают словом любую последовательность символов, разделённых пробелами. Это полезно при навигации по строкам с нестандартной пунктуацией.

### 2.2. Редактирование текста (базовые команды)

| Сочетание клавиш | Действие |
| :--- | :--- |
| `i` / `a` | Начать режим вставки перед курсором / после курсора. |
| `I` / `A` | Начать режим вставки в начале строки / в конце строки. |
| `o` / `O` | Создать пустую строку ниже текущей / выше текущей и перейти в режим вставки. |
| `Esc` или `Ctrl + [` | Выйти из режима вставки (вернуться в нормальный режим). |
| `J` | Объединить следующую строку с текущей (удаляет символ переноса строки). |
| `r[символ]` | Заменить один символ под курсором на указанный (без входа в режим вставки). |
| `R` | Перейти в режим замены (печатать поверх существующего текста). |
| `cc` | Удалить текущую строку и перейти в режим вставки. |
| `x` | Удалить (вырезать) текущий символ под курсором. |
| `X` | Удалить (вырезать) символ перед курсором. |
*Таб. 2. Горячие клавиши для редактирования текста.*

> **Важное замечание о `Ctrl + [`:** Это альтернатива `Esc`, которая часто удобнее, так как не требует отрывать руку от основной позиции набора.

### 2.3. Операторы (удаление, изменение, копирование, отступы)

Операторы применяются к тексту от текущей позиции курсора до указанного объекта перемещения.

| Сочетание клавиш | Действие |
| :--- | :--- |
| `d` | Удалить (вырезать) от курсора до позиции перемещения. |
| `c` | Удалить от курсора до позиции перемещения и перейти в режим вставки. |
| `y` | Скопировать (yank) от курсора до позиции перемещения. |
| `>` | Увеличить отступ на один уровень (в нормальном или визуальном режиме). |
| `<` | Уменьшить отступ на один уровень. |
| `J` | Объединить следующую строку с текущей (удаляет символ переноса строки). |
*Таб. 3. Основные операторы Vim.*

**Примеры использования операторов:**

| Команда | Действие |
| :--- | :--- |
| `d$` | Удалить от курсора до конца строки. |
| `c$` | Удалить от курсора до конца строки и войти в режим вставки. |
| `y$` | Скопировать от курсора до конца строки. |
| `d2w` | Удалить два слова вперёд. |
| `>G` | Увеличить отступ от текущей строки до конца файла. |
| `cc` | Удалить строку и войти в режим вставки. |
*Таб. 4. Примеры комбинирования операторов и перемещений.*

> **Примечание:** Операторы также работают в **визуальном режиме** — выделите текст, затем нажмите `d`, `c`, `y`, `>` или `<`.

### 2.4. Выделение текста (визуальный режим)

| Сочетание клавиш | Действие |
| :--- | :--- |
| `v` | Начать визуальный режим (побуквенное выделение). |
| `V` | Начать построчный визуальный режим (выделение целыми строками). |
| `Ctrl + v` | Начать блочный визуальный режим (прямоугольное выделение). |
| `o` | Перейти к другому концу выделенной области (переключить начало и конец). |
| `O` | Перейти в другой угол блока (в блочном режиме). |
| `Esc` или `Ctrl + [` | Выйти из визуального режима. |
| `gv` | Повторно выделить последний визуальный блок. |
*Таб. 5. Горячие клавиши визуального режима.*

> **Важное замечание о блочном режиме (`Ctrl + v`):** Позволяет выделять прямоугольные области текста. Это удобно для вставки столбцов или изменения отступов в нескольких строках одновременно.

### 2.5. Буфер обмена (копирование, вырезание, вставка)

| Сочетание клавиш | Действие |
| :--- | :--- |
| `yy` | Скопировать (yank) текущую строку. |
| `p` | Вставить содержимое буфера после курсора (если строка — вставить ниже). |
| `P` | Вставить содержимое буфера перед курсором (если строка — вставить выше). |
| `dd` | Удалить (вырезать) текущую строку в буфер. |
| `x` | Удалить (вырезать) текущий символ под курсором. |
| `X` | Удалить (вырезать) символ перед курсором. |
| `d` / `c` | По умолчанию копируют удалённый текст в буфер (можно вставить через `p`). |
*Таб. 6. Горячие клавиши для работы с буфером обмена.*

> **Важное замечание о буфере обмена Vim:** Команды `d`, `c`, `x`, `yy` работают с **внутренним буфером Vim**. Они не взаимодействуют с системным буфером обмена. Для вставки текста из системного буфера используйте `Ctrl + Shift + V` в терминале.

### 2.6. Поиск и замена

| Команда          | Действие                                                                  |
| :--------------- | :------------------------------------------------------------------------ |
| `/pattern`       | Искать шаблон вперёд (вниз по тексту).                                    |
| `?pattern`       | Искать шаблон назад (вверх по тексту).                                    |
| `n`              | Повторить поиск в том же направлении (следующее совпадение).              |
| `N`              | Повторить поиск в противоположном направлении (предыдущее совпадение).    |
| `:%s/old/new/g`  | Заменить все вхождения `старое` на `новое` во всём файле (но `gn` лучше). |
| `:%s/old/new/gc` | Заменить все вхождения с подтверждением каждого (`c` = confirm).          |
*Таб. 7. Команды для поиска и замены.*

> **Пояснение про `%s`:** `%` означает «во всём файле», `s` — substitute (заменить), `g` — global (все вхождения в строке). Без `g` заменяется только первое вхождение в строке.

### 2.7. Общие команды (отмена, повтор)

| Сочетание клавиш | Действие |
| :--- | :--- |
| `u` | Отменить последнее действие (undo). |
| `Ctrl + r` | Повторить отменённое действие (redo). |
| `.` (точка) | Повторить последнюю команду. |
| `Ctrl + r` + `0` | Вставить последний скопированный текст (в режиме вставки). |
| `%` | Перепрыгнуть между парными скобками `( )`, `{ }`, `[ ]`. |
| `gv` | Повторно выделить последний визуальный блок. |
*Таб. 8. Общие команды для управления изменениями.*

> **Примечание про `.`:** Команда `.` повторяет **последнее изменение**, а не последнюю команду. Например, если вы вставили слово, затем переместили курсор и нажали `.` — Vim вставит то же слово на новом месте.

*Таб. 9. Команды для поиска символов.*

> **Пример:** Если курсор стоит в строке `Hello, world!`, команда `fw` переместит его к букве `w` в слове `world`.

### 2.9. Выход из Vim

| Команда | Действие |
| :--- | :--- |
| `:w` | Сохранить файл (без выхода). |
| `:wq` | Сохранить и выйти. |
| `:q` | Выйти (не сработает, если есть несохранённые изменения). |

> **Важно:** `:q!` — это экстренный выход, который **отменяет все несохранённые правки**. Используйте его, если запутались в изменениях и хотите начать заново.

### 2.11. Метки (продвинутое)

| Команда | Действие |
| :--- | :--- |
| `m{a-z}` | Установить локальную метку (буква от `a` до `z`) в позиции курсора. |
| `m{A-Z}` | Установить глобальную метку (буква от `A` до `Z`), видимую между файлами. |
| `'{a-z}` | Переместить курсор в начало строки, где была установлена метка. |

*Таб. 12. Команды для работы с метками.*

> **Пояснение:** Метки — это закладки в тексте. Например, `ma` установит метку `a` на текущей позиции, а `'a` вернёт курсор к этой строке. Глобальные метки (`A-Z`) сохраняются между сессиями и файлами.

### 2.12. Текстовые объекты (продвинутое)

| Команда | Действие |
| :--- | :--- |
| `di(` / `di)` | Удалить всё внутри ближайших круглых скобок (delete inside). |
| `di{` / `di}` | Удалить всё внутри ближайших фигурных скобок. |
| `di"` / `di'` | Удалить всё внутри ближайших кавычек. |
| `yi(` / `yi)` | Скопировать всё внутри ближайших круглых скобок (yank inside). |
| `vi(` | Выделить всё внутри ближайших круглых скобок (visual inside). |
*Таб. 13. Команды для работы с текстовыми объектами.*

> **Пример:** Если курсор находится внутри `def (arg1, arg2, arg3)`, команда `di(` удалит всё внутри скобок (оставит `def ()`). Без текстовых объектов пришлось бы делать `T(dt)` — это сложнее и медленнее.

## 3. Разбор сложных ситуаций и типичных вопросов

### 3.1. Раскладка клавиатуры — частая ошибка

**Вопрос:** *Почему в Vim перестали работать команды? Проверьте, не переключились ли вы в русскую раскладку!*

**Причина:** Vim **не понимает русские буквы как команды**. Если вы нажимаете `i` в русской раскладке, Vim видит символ `ш`, а не команду `i` — и ничего не происходит. Это одна из самых частых ошибок у новичков.

**Решение:**
- Перед вводом команды всегда проверяйте раскладку (она должна быть английской).
- Если вы уже в русской раскладке, переключитесь на английскую (`Alt + Shift` или `Ctrl + Shift`) и повторите команду.
- Если вы случайно ввели текст в русской раскладке, его можно удалить и перепечатать.

### 3.2. Разница между `w` и `W`

**Вопрос:** *В чём разница между `w` и `W`?*

**Технический ответ:** `w` и `b` перемещаются по **границам слов** (буквы, цифры, подчёркивания). `W` и `B` перемещаются по **последовательностям непробельных символов** (игнорируют пунктуацию). Например, в строке `one,two;three`:
- `w` остановится на `,` и `;`.
- `W` остановится только на пробелах, перепрыгнув через `one,two;three` как одно слово.

Это важно для навигации по коду или строкам с нестандартной пунктуацией.

### 3.3. Что значит `:%s/old/new/g` и почему `gn` лучше?

**Вопрос:** *В шпаргалке написано `:%s/old/new/g`, но добавлено «но gn лучше». Что это значит?*

**Технический ответ:** `:%s/old/new/g` заменяет все вхождения `old` на `new` во всём файле без предварительного просмотра. Это может быть опасно, если вы ошиблись в шаблоне.

**Более безопасный способ:**
1. Используйте `gn` для поиска всех вхождений:
   ```
   /old
   ```
   Нажмите `gn` — Vim выделит все вхождения.

2. Если всё верно, выполните замену:
   ```
   :%s/old/new/g
   ```
3. Или используйте `:%s/old/new/gc` — с подтверждением каждого вхождения.

Таким образом, `gn` (следующее совпадение) даёт визуальный контроль перед заменой.

## 4. Лимиты, оптимизация и масштабирование

- **Высокий порог входа:** Vim требует времени на освоение, но это окупается скоростью и эффективностью.
- **Предустановлен везде:** Это делает Vim идеальным выбором для работы на серверах и встраиваемых системах.
- **Плагины расширяют возможности:** Менеджеры плагинов (`vim-plug`, `Vundle`) позволяют настроить Vim под любые задачи.
- **Альтернативы:** Nano подходит для простых задач, Neovim — для тех, кому нужен более современный и быстрый инструмент.

## 5. Расширенный ИБ-контекст и инженерный FAQ

### 1. Векторы атак и уязвимости (Security Context)

- **Редактирование системных файлов:** Использование `sudo vim` для редактирования системных файлов (например, `/etc/ssh/sshd_config`) требует осторожности. Ошибки в конфигурации могут привести к неработоспособности служб или системы в целом.
- **Плагины из ненадёжных источников:** Установка плагинов без проверки может привести к компрометации системы. Рекомендуется использовать только проверенные менеджеры плагинов и официальные репозитории.
- **Приватные ключи в буфере обмена:** Если вы скопировали приватный ключ (`yy`), он остаётся во внутреннем буфере Vim до перезаписи. Если сессия не завершена, этот буфер может быть доступен другому процессу. Рекомендуется очищать буфер после копирования чувствительных данных.

### 2. Инженерный FAQ (на основе разбора дискуссий)

- **Вопрос:** *Что такое `gn` и зачем он нужен?*  
  **Технический ответ:** `gn` — это команда, которая выделяет следующее совпадение шаблона поиска. Она позволяет **визуально проверить**, что именно будет заменено, прежде чем выполнять `:%s`. Это значительно снижает риск случайной замены не того текста.

- **Вопрос:** *Как вставить текст из системного буфера обмена в Vim?*  
  **Технический ответ:** Vim по умолчанию не использует системный буфер. Для вставки из системного буфера в терминале используйте `Ctrl + Shift + V`. Если вы хотите, чтобы Vim использовал системный буфер, настройте `clipboard` в `.vimrc` (например, `set clipboard=unnamed` для Linux).

- **Вопрос:** *Как быстро переместиться к парной скобке?*  
  **Технический ответ:** Используйте команду `%`. Она перепрыгивает между парными `( )`, `{ }`, `[ ]`. Это работает, даже если курсор находится не на самой скобке, а внутри блока.

- **Вопрос:** *Почему `:q!` иногда не срабатывает?*  
  **Технический ответ:** `:q!` всегда срабатывает, если вы находитесь в командном режиме. Если команда не вводится, возможно, вы всё ещё в режиме вставки — нажмите `Esc` несколько раз, затем введите `:q!`.

- **Вопрос:** *Как отключить подсветку результатов поиска?*  
  **Технический ответ:** После поиска Vim подсвечивает все совпадения. Чтобы отключить подсветку, выполните команду `:nohlsearch` (сокращённо `:noh`). Это временное отключение; подсветка вернётся при новом поиске.

## Заключение

Vim — это мощный текстовый редактор, который, несмотря на высокий порог входа, предоставляет огромную скорость и гибкость при редактировании текста в терминале. Понимание режимов работы, базовых операторов, визуального выделения и команд управления файлами позволяет выполнять сложные операции без использования мыши. Знание продвинутых техник (поиск символов, метки, текстовые объекты) делает работу ещё более эффективной. Vim предустановлен практически в любом дистрибутиве Linux, и его освоение — обязательный шаг для системного администратора и разработчика.
