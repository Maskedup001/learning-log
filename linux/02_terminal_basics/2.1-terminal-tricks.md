# Тема 2.1: Трюки и лайфхаки в Терминале

В данной теме рассматриваются приёмы повышения эффективности работы в командной строке Linux: очистка терминала, редактирование командной строки, получение справочной информации, поиск и история команд. Изучаются как встроенные команды, так и горячие клавиши, позволяющие ускорить повседневные операции. В разделе разбираются реальные вопросы и нюансы, обнаруженные пользователями в процессе обучения.

---

## 1. Очистка терминала и управление выводом — Базовые свойства

* **Контекст/Уровень:** Системное администрирование / Пользовательский интерфейс командной строки.
* **Основное назначение:** Управление визуальным выводом терминала для повышения читаемости.
* **Принцип работы:** Команды и горячие клавиши позволяют очищать экран, сбрасывать настройки терминала и управлять отображением текста.

### 1.1. Команда `clear`

```bash
clear
```

**Действие:** Полностью очищает видимое окно терминала. История команд при этом сохраняется — можно вернуться к предыдущему выводу с помощью прокрутки колесом мыши.

**Горячая клавиша:** `Ctrl + L` — выполняет то же действие, что и команда `clear`.

> **Нюанс:** Команда `clear` очищает экран целиком, а `Ctrl + L` очищает экран, но сохраняет возможность прокрутки. Это позволяет быстро вернуться к предыдущему выводу.

### 1.2. Команда `reset`

```bash
reset
```

**Действие:** Используется в случаях, когда вывод терминала «сломался» — например, после вывода бинарных данных или спецсимволов, которые нарушили работу терминала. Команда полностью восстанавливает корректное отображение.

## 2. Редактирование командной строки — Базовые свойства

* **Контекст/Уровень:** Работа с командной строкой (Bash-оболочка).
* **Основное назначение:** Ускорение ввода и редактирования команд.
* **Принцип работы:** Горячие клавиши позволяют удалять текст слева или справа от курсора, перемещаться по строке и управлять историей.

### 2.1. Удаление текста

| Горячая клавиша | Действие |
| :--- | :--- |
| `Ctrl + U` | Удаляет всё от курсора до начала строки. |
| `Ctrl + K` | Удаляет всё от курсора до конца строки. |
| `Ctrl + W` | Удаляет одно слово перед курсором. |
*Таб. 1. Горячие клавиши для удаления текста.*

> **Важно:** `Ctrl + U` и `Ctrl + K` выполняют **вырезание**, а не только удаление. Вырезанный текст можно вставить с помощью `Ctrl + Y`. Это полезно для переноса части команды в другое место.

### 2.2. Перемещение курсора

| Горячая клавиша | Действие |
| :--- | :--- |
| `Ctrl + ←` / `Ctrl + →` | Перемещение на одно слово влево / вправо. |
| `Home` / `End` | Перемещение в начало / конец строки. |
| `Ctrl + A` / `Ctrl + E` | Перемещение в начало / конец строки (аналоги `Home` / `End`). |
| `Ctrl + P` / `Ctrl + N` | Перемещение к предыдущей / следующей команде в истории. |
*Таб. 2. Горячие клавиши для перемещения курсора.*

### 2.3. Другие полезные комбинации

| Горячая клавиша | Действие |
| :--- | :--- |
| `Ctrl + L` | Очистка экрана (аналог `clear`). |
| `Ctrl + R` | Интерактивный поиск по истории команд. |
| `Ctrl + C` | Прерывание текущей команды или процесса. |
| `Ctrl + Y` | Вставить вырезанный текст (после `Ctrl + U` / `Ctrl + K`). |
*Таб. 3. Полезные комбинации клавиш.*

## 3. Получение справочной информации — Базовые свойства

* **Контекст/Уровень:** Работа с документацией в командной строке.
* **Основное назначение:** Получение информации о командах и их опциях.
* **Принцип работы:** Разные команды предоставляют справку на разных уровнях детализации.

### 3.1. `whatis` — краткая справка в одну строку

```bash
whatis clear
whatis history
```

**Действие:** Выводит краткое описание команды (одну строку). Информация берётся из man-страниц.

> **Примечание:** Если команда `whatis` не работает в Ubuntu, необходимо установить и обновить базу данных:
> ```bash
> sudo apt update && sudo apt install --reinstall man-db
> sudo mandb
> ```

> **Почему это нужно?** Команда `whatis` берёт информацию из базы данных man-страниц. Если эта база не установлена или устарела, `whatis` не будет работать. Установка `man-db` и выполнение `mandb` обновляют эту базу.

### 3.2. `help` — справка для встроенных команд оболочки

```bash
help cd
help history
```

**Действие:** Используется для встроенных команд Bash (built-ins). Для внешних команд этот способ не работает.

### 3.3. `--help` — справка для большинства команд

```bash
history --help
ls --help
```

**Действие:** Универсальный способ получить краткую справку по команде. Работает для большинства внешних утилит.

> **Сравнение:** `help` работает только для встроенных команд Bash, а `--help` — для любых команд (включая внешние утилиты). Например:
> - `help systemctl` — выдаст ошибку.
> - `systemctl --help` — покажет справку.

### 3.4. `man` — полное руководство пользователя

```bash
man clear
man history
```

**Действие:** Открывает подробную документацию с описанием всех опций. Навигация осуществляется стрелками, `Page Up` / `Page Down` или колесом мыши. Выход — по нажатию клавиши `q`.

> **Расшифровка:** `man` — от английского *manual* (руководство).

### 3.5. `info` — альтернативная документация

```bash
info clear
```

**Действие:** Более подробная документация в формате гипертекста. Иногда содержит больше информации, чем `man`. Выход — по нажатию `q` (или `Ctrl + C` как жёсткое прерывание).

### 3.6. Регистр букв в Linux

Все команды вводятся в **нижнем регистре**. Пример:
- `man` — работает.
- `MAN` — выдаст ошибку `command not found`.

## 4. Поиск команд — Базовые свойства

* **Контекст/Уровень:** Работа с командной строкой.
* **Основное назначение:** Быстрый поиск команд по названию или описанию.
* **Принцип работы:** Используются автодополнение и поиск по базе данных man-страниц.

### 4.1. Двойной `Tab` — автодополнение с подсказкой

Набрать начало команды и нажать `Tab` дважды:

```bash
hi<Tab><Tab>
```

**Действие:** Терминал покажет все команды, начинающиеся с `hi` (например, `history`, `hit` и др.).

### 4.2. `apropos` — поиск команд по описанию

```bash
apropos his
```

**Действие:** Ищет команды, в названии или описании которых встречается указанная строка. Полезно, когда забыли точное название команды, но помните её назначение.

## 5. История команд — Базовые свойства

* **Контекст/Уровень:** Работа с историей Bash.
* **Основное назначение:** Просмотр, поиск и повторное выполнение ранее введённых команд.
* **Принцип работы:** Bash сохраняет историю команд в файле `~/.bash_history`. Управление историей осуществляется через команду `history` и горячие клавиши.

### 5.1. Просмотр истории

```bash
history          # показать всю историю
history 10       # показать последние 10 команд
history 5        # показать последние 5 команд
```

### 5.2. Запуск команд из истории

Каждая команда в выводе `history` имеет номер. Используйте `!` для повторного выполнения:

| Синтаксис | Действие |
| :--- | :--- |
| `!37` | Выполнить команду с номером 37. |
| `!!` | Выполнить предыдущую команду. |
| `!-6` | Выполнить шестую команду с конца списка. |
*Таб. 4. Синтаксис запуска команд из истории.*

> **Примечание:** `!!` часто используется вместе с `sudo`:  
> `sudo !!` — выполнить предыдущую команду с правами администратора.

### 5.3. Поиск по истории

**Горячая клавиша:** `Ctrl + R`

- Начать вводить фрагмент команды.
- Терминал показывает последнее совпадение.
- `Ctrl + R` повторно — переход к более ранним совпадениям.
- `Enter` — выполнить найденную команду.
- `Tab` — выбрать команду для редактирования.

> **Особенность работы `Ctrl + R`:** Поиск начинается с последнего совпадения. При повторном нажатии `Ctrl + R` осуществляется переход к более ранним совпадениям. Это может привести к неожиданным результатам, если в истории много похожих команд.

### 5.4. Управление историей

| Команда / Действие | Пояснение |
| :--- | :--- |
| `history -c` | Очистить историю команд текущей сессии (в оперативной памяти). |
| `history -c && history -w` | Очистить историю и сохранить изменения в файл. |
| `<пробел> команда` | Команда с пробелом в начале не попадает в историю (если включена опция `HISTCONTROL=ignorespace`). |
*Таб. 5. Команды для управления историей.*

**Пример:**
```bash
 ls          # обычная команда — попадёт в историю
 cd /        # команда с пробелом — не попадёт в историю
```

> **Замечание:** Трюк с пробелом работает не во всех эмуляторах терминала и не во всех дистрибутивах. В некоторых системах (например, Manjaro) может потребоваться настройка переменной `HISTCONTROL`.

## 6. Разбор типичных ошибок и вопросов из обсуждений

### 6.1. Почему `history -c` не очищает историю полностью?

**Вопрос:** *`history -c` просто очищает историю, лучше писать `history -c && history -w` чтоб очистить и записать изменения, и после выхода-захода в терминал история была очищена.*

**Ответ:** Команда `history -c` очищает историю только в оперативной памяти текущей сессии. Для полной очистки и сохранения изменений в файле `~/.bash_history` рекомендуется использовать `history -c && history -w`.

### 6.2. Почему команда `whatis` не работает?

**Вопрос:** *У меня сразу не работала команда `whatis`, сначала понадобилось установить пакет.*

**Ответ:** Для корректной работы `whatis` необходимо установить и обновить базу данных man-страниц:

```bash
sudo apt update && sudo apt install --reinstall man-db
sudo mandb
```

### 6.3. В чём разница между `help` и `--help`?

**Вопрос:** *`help <команда>` и `<команда> --help` — выдаёт одинаковый результат?*

**Ответ:** Это похожие, но разные механизмы:
- `help` — это встроенная команда Bash, работает **только** для встроенных команд (built-ins), например, `cd`, `history`.
- `--help` — это флаг самой команды, работает для **любых** команд (включая внешние утилиты, например, `systemctl`, `grep`).

Пример для понимания:
```bash
help systemctl      # Ошибка: help не знает о systemctl
systemctl --help    # Покажет справку по systemctl
```

### 6.4. Как выйти из `info`?

**Вопрос:** *Как выйти из `info`?*

**Ответ:** Штатный способ выхода — нажать клавишу `q`. Комбинация `Ctrl + C` тоже сработает, но это жёсткое прерывание, а не корректный выход.

### 6.5. Почему `Ctrl + R` работает не так, как ожидается?

**Вопрос:** *Поиск с использованием `Ctrl + R` работает совершенно не так, как мы ожидаем...*

**Ответ:** `Ctrl + R` начинает поиск с самого последнего совпадения. При повторном нажатии `Ctrl + R` осуществляется переход к более ранним совпадениям. Это позволяет найти нужную команду, но требует понимания направления поиска.

**Альтернативный совет:** Для поиска по истории также можно использовать `history | grep "команда"`.

### 6.6. Почему `whatis git` выдаёт «stupid content tracker»?

**Вопрос:** *Если ввести в терминал `whatis git`, выдаст одно из значений — 'stupid content tracker'. Похоже, у создателей линукса есть чувство юмора.*

**Ответ:** Команда `whatis` подтягивает информацию из man-страниц, которые пишут разработчики конкретного софта. В случае с `git` это чувство юмора принадлежит создателю Git — Линусу Торвальдсу, а не создателям Linux.

### 6.7. Трюк с пробелом работает не на всех системах

**Вопрос:** *Скрытие команд из истории с помощью пробела не сработало в моём терминале (Manjaro, Konsole).*

**Ответ:** Трюк с пробелом работает только в том случае, если в оболочке включена опция `HISTCONTROL=ignorespace`. В некоторых дистрибутивах и эмуляторах терминала эта опция отключена по умолчанию. Для проверки выполните:
```bash
echo $HISTCONTROL
```

## 8. Расширенный ИБ-контекст и инженерный FAQ

### 1. Векторы атак и уязвимости (Security Context)

- **Скрытие команд из истории с помощью пробела** — может использоваться для сокрытия действий от системных администраторов. Однако системные логи (`auditd`, `syslog`) всё равно сохраняют все выполненные команды.
- **Очистка истории (`history -c`)** — может быть использована злоумышленником для удаления следов активности. В производственных средах рекомендуется настройка журналирования на уровне ОС.
- **Использование `sudo !!`** — удобно, но требует осторожности, так как повторяет команду без проверки.

### 2. Инженерный FAQ (На основе разбора дискуссий)

- **Вопрос:** *Как полностью исключить сохранение команды в логах?*  
  **Ответ:** Полностью исключить сохранение команды в системных логах без прав администратора невозможно. Эти логи контролируются на уровне ОС и политик безопасности.

- **Вопрос:** *Почему `clear` и `Ctrl + L` ведут себя по-разному?*  
  **Ответ:** `clear` очищает экран полностью, а `Ctrl + L` очищает экран, но сохраняет возможность прокрутки.

- **Вопрос:** *Можно ли использовать `Ctrl + Y` для вставки вырезанного текста?*  
  **Ответ:** Да, `Ctrl + Y` вставляет текст, вырезанный с помощью `Ctrl + U` или `Ctrl + K`.

- **Вопрос:** *Где хранится история команд?*  
  **Ответ:** История команд хранится в файле `~/.bash_history` (для Bash).

- **Вопрос:** *Есть ли альтернативы `Ctrl + R` для поиска по истории?*  
  **Ответ:** Да, можно использовать `history | grep "команда"` для быстрого поиска конкретной команды.

Практическое применение этих знаний закладывает фундамент для дальнейшего изучения более сложных аспектов управления системами.
