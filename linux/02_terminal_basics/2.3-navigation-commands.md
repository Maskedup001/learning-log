# Тема 2.3: Основные команды для навигации по папкам

Изучение базовых команд для навигации по файловой системе Linux: определение текущей директории (`pwd`), смена директории (`cd`), просмотр содержимого (`ls` и `ll`), а также работа с абсолютными и относительными путями, скрытыми файлами и специальными обозначениями (`.`, `..`, `~`). В конце приведены практические рекомендации и разбор типичных вопросов.

---

## 1. Основные команды — Базовые свойства

- **Контекст/Уровень:** Системное администрирование / Файловая система.
- **Основное назначение:** Перемещение по файловой системе Linux и получение информации о её структуре.
- **Принцип работы:** Команды `pwd`, `cd` и `ls` являются встроенными командами оболочки Bash. Они взаимодействуют с файловой системой через системные вызовы и предоставляют пользователю информацию о текущем местоположении и содержимом директорий.

> **Важное замечание о терминах:** В Linux принято использовать термин «каталог» или «директория», а не «папка», хотя в обиходе все эти термины являются синонимами.

---

## 2. Команды для навигации

### 2.1. `pwd` — определение текущей директории

```bash
pwd
```

**Действие:** Выводит полный путь к текущей директории (Print Working Directory).

**Пример вывода:**
```bash
/home/itguy
```

### 2.2. `cd` — смена директории

```bash
cd [путь]
```

**Действие:** Перемещает пользователя в указанную директорию (Change Directory).

**Основные варианты использования:**

| Команда         | Действие                                              |
| :-------------- | :---------------------------------------------------- |
| `cd /home`      | Перейти в директорию `/home` (абсолютный путь).       |
| `cd itguy`      | Перейти в поддиректорию `itguy` (относительный путь). |
| `cd ..`         | Перейти в родительскую директорию (на уровень выше).  |
| `cd ../..`      | Перейти на два уровня выше.                           |
| `cd /`          | Перейти в корневую директорию.                        |
| `cd ~` или `cd` | Перейти в домашнюю директорию текущего пользователя.  |
| `cd -`          | Перейти в предыдущую директорию (с возвратом назад).  |
*Таб. 1. Основные варианты использования команды `cd`.*

> **Пояснение:** Обозначение `..` означает «родительская директория», то есть папку на один уровень выше. Обозначение `~` — домашнюю директорию пользователя.

> **Дополнение:** `cd -` полезно, когда вы перешли в другую папку, но хотите быстро вернуться обратно. Это особенно удобно при работе с двумя часто используемыми директориями.

> **Важно:** Команда `cd` без параметров выполняет то же действие, что и `cd ~` — перемещает в домашнюю директорию текущего пользователя.

### 2.3. Абсолютные и относительные пути

| Тип пути          | Начало                  | Описание                                                                      | Пример        |
| :---------------- | :---------------------- | :---------------------------------------------------------------------------- | :------------ |
| **Абсолютный**    | `/`                     | Полный путь от корня файловой системы. Не зависит от текущего местоположения. | `cd /var/log` |
| **Относительный** | любой символ, кроме `/` | Путь вычисляется относительно текущей директории.                             | `cd ../etc`   |
*Таб. 2. Сравнение абсолютных и относительных путей.*

> **Дополнение:** Родительская директория — это директория, в которой находится текущая папка. Например, если вы в `/home/itguy/Documents`, то родительская — `/home/itguy`.

> **Нюанс про относительные пути:** Относительный путь работает из любой директории, но нужно правильно указывать путь относительно текущего местоположения. Например, находясь в `/home/itguy`, команда `cd Documents` переместит в `/home/itguy/Documents` (относительный путь). А команда `cd /Documents` попытается перейти в корневую директорию `Documents`, которой скорее всего не существует.

### 2.4. Специальные обозначения в путях

| Обозначение | Значение |
| :--- | :--- |
| `.` | Текущая директория. |
| `..` | Родительская директория. |
| `~` | Домашняя директория текущего пользователя. |
*Таб. 3a. Специальные обозначения в путях.*

**Пример:** `cd ../../var` — подняться на два уровня вверх, затем войти в директорию `var`.

## 3. Команда `ls` — просмотр содержимого директории

```bash
ls [ключи] [путь]
```

**Действие:** Выводит список файлов и поддиректорий в указанном пути.

### 3.1. Основные ключи

| Ключ | Описание                                                                                          |
| :--- | :------------------------------------------------------------------------------------------------ |
| `-a` | Показывает все файлы, включая скрытые (начинающиеся с точки).                                     |
| `-l` | Выводит содержимое в виде таблицы (подробная информация: права доступа, владелец, размер, дата).  |
| `-h` | Выводит размеры файлов в «человекочитаемом» формате (КБ, МБ) — обычно используется вместе с `-l`. |
| `-1` | Выводит содержимое по одному файлу/директории на строку (без лишней информации).                  |
| `-F` | Добавляет символы к именам: `/` для директорий, `*` для исполняемых файлов.                       |
*Таб. 4. Основные ключи команды `ls`.*

### 3.2. Примеры использования

```bash
ls              # список файлов в текущей директории
ls -a           # все файлы, включая скрытые
ls -l           # подробный (табличный) вывод
ls -la          # подробный вывод со скрытыми файлами
ls /var         # содержимое директории /var
ls -la /var     # подробный вывод со скрытыми файлами для /var
ls -1           # список по одному на строку (удобно для скриптов)
ls -lF          # подробный вывод с символами для директорий и файлов
```

> **Примечание:** Порядок ключей не имеет значения. `ls -al`, `ls -la` и `ls -a -l` дают одинаковый результат.

> **Примечание:** Ключ `-1` особенно полезен в скриптах, когда нужно обработать каждую запись по отдельности, например, в цикле `for` или при передаче в `grep` и `xargs`

### 3.3. Скрытые файлы и директории

В Linux скрытые файлы и папки обозначаются начальной точкой в имени (например, `.bashrc`, `.config`). Команда `ls` без ключа `-a` их не показывает. Чтобы увидеть скрытые файлы, используйте `ls -a` или `ls -la`.

### 3.4. Псевдоним `ll`

Во многих дистрибутивах Linux (включая Ubuntu) команда `ll` является псевдонимом для `ls -alF`. Она выводит подробный список всех файлов, включая скрытые, а также добавляет слеш (`/`) к именам директорий.

```bash
ll              # эквивалентно ls -alF
```

> **Важно:** `ll` — это **не отдельная команда**, а псевдоним (alias), определённый в файле `~/.bashrc` (или `~/.zshrc` для Zsh). Если вы хотите изменить его поведение, отредактируйте этот файл. Например, можно сделать `alias ll='ls -alh'` для отображения размеров в читаемом формате.

> **Примечание:** В некоторых дистрибутивах `ll` может быть настроен как `ls -al` (без `-F`). Чтобы узнать точное поведение, выполните `type ll` — терминал покажет, что именно подставляется.

## 4. Разбор сложных ситуаций и типичных вопросов из обсуждений

### 4.1. Проблема с кириллицей в `cd`

**Вопрос:** *Почему при использовании `cd` с кириллическими названиями папок возникает ошибка?*  
**Ответ:** Проблема может быть связана с кодировкой файловой системы или настройками терминала. Чтобы решить её, попробуйте:
- **Использовать абсолютный путь:** `cd /путь/к/Мой_каталог`.
- **Заключить имя в кавычки:** `cd 'Мой_каталог'`.
- **Проверить кодировку файловой системы:** например, в `ext4` кодировка обычно `UTF-8`, которая поддерживает кириллицу.
- **Настроить терминал:** убедитесь, что он использует правильную кодировку (например, `export LANG=ru_RU.UTF-8`).

### 4.2. Разница между `ls -l` и `ll`

**Вопрос:** *Почему в выводе команд `ls -l` и `ll` есть разница в виде слеша в конце строк?*  
**Ответ:** Это связано с тем, что `ll` является псевдонимом для `ls -alF`. Ключ `-F` добавляет слеш (`/`) к именам директорий, чтобы их было проще отличить от обычных файлов. Это стандартное поведение для многих дистрибутивов.

### 4.3. Абсолютные и относительные пути

**Вопрос:** *В чём разница между абсолютным и относительным путём?*  
**Ответ:** Абсолютный путь начинается с корня `/` и не зависит от текущего местоположения. Относительный путь вычисляется относительно текущей директории и может использовать обозначения `.` (текущая) и `..` (родительская).

### 4.4. Что означают точки в выводе `ls -la`

**Вопрос:** *Что означают точки в выводе `ls -la`?*  
**Ответ:** В любой директории есть две специальные записи:
- `.` — ссылка на текущую директорию.
- `..` — ссылка на родительскую директорию.
Они появляются в выводе `ls -la` всегда и предназначены для навигации.

### 4.5. Что такое `ll` и почему он работает

**Вопрос:** *Что такое `ll` и почему он работает?*  
**Ответ:** `ll` — это не отдельная команда, а псевдоним (alias), определённый в конфигурационном файле оболочки (например, в `~/.bashrc`). Он обычно эквивалентен `ls -alF` и позволяет быстро получить подробный список всех файлов, включая скрытые. Откройте свой `~/.bashrc` и найдите строку, начинающуюся с `alias ll=`, чтобы увидеть точную команду.

### 4.6. Почему псевдоним `ll` использует `-al`, а не `-alh`

**Вопрос:** *Почему псевдоним `ll` используется с ключами `-al`, а не `-alh`?*  
**Ответ:** Потому что так прописано в конфигурационных файлах оболочки по умолчанию (например, `~/.bashrc` или `~/.zshrc`). Вы можете изменить это поведение, отредактировав файл и добавив `alias ll='ls -alh'`.

### 4.7. Домашняя директория и её назначение

**Вопрос:** *Как назначается домашняя директория?*  
**Ответ:** Домашняя директория (`~`) — это персональный каталог для каждого пользователя. Обычно она находится в `/home/имя_пользователя`, а для суперпользователя (`root`) — в `/root`. Она создаётся при создании учётной записи и доступна только этому пользователю и администратору. Однако при настройке служб часто создаются пользователи без домашней директории для экономии места — это зависит от конкретных задач.

> **Уточнение:** например, для пользователя `itguy` домашняя директория — это `/home/itguy`. Именно там находятся его личные файлы и настройки (например, `.bashrc`, `.config`).

> **Дополнение:** В домашней директории (`~`) у каждого пользователя есть скрытые файлы и папки (начинающиеся с точки). Они содержат настройки софта (например, `.bashrc`, `.config`). Эти файлы можно перенести на другой компьютер, чтобы не настраивать программы заново. Однако будьте осторожны: не выкладывайте в интернет приватные ключи или историю команд.

## 5. Лимиты, оптимизация и масштабирование

- **Ключи можно комбинировать:** Порядок ключей в `ls` не важен. `ls -la`, `ls -al`, `ls -l -a` дают одинаковый результат.
- **Псевдонимы ускоряют работу:** Определение псевдонимов (например, `alias ll='ls -alh'`) в файле `~/.bashrc` позволяет сократить время на ввод команд и настроить поведение под свои предпочтения.
- **Абсолютные пути надёжнее:** В скриптах и автоматизированных задачах всегда предпочтительнее использовать абсолютные пути, чтобы избежать ошибок, связанных с изменением текущей директории.
- **Разница между стандартными командами и алиасами:** Когда вы вводите команду в терминале, Bash сначала ищет алиасы, потом функции, затем встроенные команды и только после этого обращается к переменной `$PATH`. Это важно понимать при отладке неожиданного поведения.

## 6. Расширенный ИБ-контекст и инженерный FAQ

### 1. Векторы атак и уязвимости (Security Context)

- **Скрытые файлы и безопасность:** Скрытые файлы (начинающиеся с точки) часто содержат конфигурации и приватные данные (например, `.bash_history`, `.ssh/authorized_keys`). Злоумышленник, получивший доступ к системе, может просмотреть их с помощью `ls -la`. Рекомендуется ограничить права доступа к эти файлам (`chmod 600`).
- **Подмена псевдонимов:** Если злоумышленник имеет доступ к файлу `~/.bashrc`, он может подменить псевдоним `ll` на вредоносную команду, которая будет выполняться при каждом запуске терминала. Рекомендуется проверять целостность конфигурационных файлов и использовать минимальные права.

### 2. Инженерный FAQ (На основе разбора дискуссий)

- **Вопрос:** *Что такое FHS и зачем он нужен?*  
  **Ответ:** FHS (Filesystem Hierarchy Standard) — это стандарт иерархии файловой системы, описывающий, какие каталоги должны быть в корневой директории `/`. Большинство дистрибутивов следуют этому стандарту. Однако существуют дистрибутивы с отклонениями: **NixOS** использует `/nix/store`, **Guix System** — `/gnu/store`, а некоторые встраиваемые системы могут вообще не соблюдать FHS.

- **Вопрос:** *Что такое POSIX и зачем он нужен?*  
  **Ответ:** POSIX (Portable Operating System Interface) — это набор стандартов IEEE, определяющих системные интерфейсы, функции языка C и командные оболочки для обеспечения совместимости программ между разными операционными системами (Linux, macOS и другие Unix-подобные системы).

- **Вопрос:** *Что означают скрытые файлы в домашней директории?*  
  **Ответ:** В `~` у каждого пользователя есть скрытые файлы и папки (начинающиеся с точки). Они содержат настройки софта, который использует пользователь (например, `.bashrc`, `.zshrc`, папка `.config`). Эти файлы можно перенести на другой компьютер, чтобы не настраивать программы заново. Однако нужно быть осторожным: не выкладывать в сеть приватные ключи или историю команд, так как удалить их из интернета невозможно.

- **Вопрос:** *Почему команда `cd` не работает с кириллицей?*  
  **Ответ:** Это проблема кодировки терминала или файловой системы. Используйте абсолютные пути или кавычки: `cd 'Мой_каталог'`.

- **Вопрос:** *Что такое `ll` и почему он работает?*  
  **Ответ:** `ll` — это псевдоним для `ls -alF`, определённый в файле `~/.bashrc`. Вы можете настроить его под свои нужды, отредактировав этот файл.

- **Вопрос:** *Почему псевдоним `ll` используется с ключами `-al`, а не `-alh`?*  
  **Ответ:** Потому что так прописано в конфигурационных файлах по умолчанию. Вы можете изменить это поведение.

- **Вопрос:** *В чём разница между `cd` с аргументом и без? (`cd` и `cd /`)*  
  **Ответ:** `cd` без аргументов всегда перемещает в домашнюю директорию текущего пользователя (`~`). С аргументом (`cd /`) — перемещает в корневую директорию системы (`/`). Это два совершенно разных места..

- **Вопрос:** *Что такое домашняя директория и как она назначается?*  
  **Ответ:** Домашняя директория (`~`) — это персональный каталог для каждого пользователя. Обычно она находится в `/home/имя_пользователя`, а для `root` — в `/root`. Она создаётся при создании учётной записи и доступна только этому пользователю (и администратору).

- **Вопрос:** _Относительный путь работает только из родительской папки?_  
  **Ответ:** Нет. Относительный путь работает из любой директории. Просто нужно правильно указать путь относительно текущего местоположения. Например, находясь в `/home/itguy`, команда `cd Documents` переместит в `/home/itguy/Documents`, а команда `cd ../` поднимет на уровень выше.

## Заключение

Команды `pwd`, `cd` и `ls` являются фундаментом для работы с файловой системой в Linux. Понимание абсолютных и относительных путей, умение использовать ключи `ls` (-a, -l, -h, -1, -F) и знание специальных обозначений (`.`, `..`, `~`) позволяют быстро и эффективно ориентироваться в системе. Важно также понимать, что такое псевдонимы и как они работают, чтобы настраивать терминал под свои нужды. Эти навыки необходимы для дальнейшего изучения более сложных операций с файлами и директориями.
