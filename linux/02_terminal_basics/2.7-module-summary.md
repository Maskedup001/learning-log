## 2. Разбор контрольных вопросов (с пояснениями)

### 2.1. Какое сочетание клавиш очищает текст слева от курсора?

**Вопрос:** *Какое сочетание клавиш мы используем, чтобы очистить/удалить текст слева от курсора (в строке для ввода команд)?*

**Варианты ответов:**
- `Ctrl + L`
- **`Ctrl + U`**
- `Ctrl + K`

**Правильный ответ:** `Ctrl + U`

**Разбор:**
- `Ctrl + U` — удаляет текст **от курсора до начала строки** (слева от курсора).
- `Ctrl + K` — удаляет текст **от курсора до конца строки** (справа от курсора).
- `Ctrl + L` — очищает экран терминала (аналог `clear`), не удаляет текст в строке ввода.

> **Инженерный FAQ:** *Как запомнить разницу между `Ctrl + U` и `Ctrl + K`?*  
> Можно использовать мнемонику: **U** — от английского *Up* (до начала), **K** — от *Key* (клавиша, которая идёт до конца). Либо просто запомнить по аналогии: `Ctrl + U` удаляет всё, что «уходит» вверх от курсора.

### 2.2. Какую команду использовать для вызова справки в терминале?

**Вопрос:** *Какую команду мы используем для вызова справки в терминале Linux?*

**Варианты ответов:**
- команду `whatis`
- опцию `--help`
- команду `man`
- **Все ответы выше**

**Правильный ответ:** *Все ответы выше*

**Разбор:**
- `whatis` — даёт краткое описание команды (одна строка).
- `--help` — универсальная опция для краткой справки по большинству команд.
- `man` — открывает полноценное руководство пользователя (manual).

Эти три способа не исключают, а **дополняют друг друга**:
- `whatis` — для быстрого ознакомления.
- `--help` — когда нужно вспомнить ключи.
- `man` — для глубокого изучения.

> **Инженерный FAQ:** *Какая разница между `help` и `--help`?*  
> `help` — это встроенная команда оболочки Bash, которая работает **только для встроенных команд** (например, `cd`, `history`). `--help` — это флаг самой команды, который работает для **любых команд**, включая внешние утилиты.

### 2.3. Какая команда используется для переименования файла?

**Вопрос:** *Какая команда используется для переименования файла?*

**Варианты ответов:**
- `rn`
- `rm`
- `cp`
- **`mv`**

**Правильный ответ:** `mv`

**Разбор:**
- `mv` (Move) — используется для перемещения файлов и каталогов, а также для их **переименования**, так как в Linux нет отдельной команды для переименования.
- `rn` — такой команды не существует (это ловушка).
- `rm` — удаляет файлы и каталоги.
- `cp` — копирует файлы и каталоги.

> **Важно:** Переименование через `mv` работает только в том случае, если источник и цель находятся в одной директории. Если цель находится в другой директории, происходит **перемещение**, а не переименование.
