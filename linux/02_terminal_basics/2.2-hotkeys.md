# Тема 2.2: Список горячих клавиш в терминале Linux (Bash)

В данной теме представлен структурированный справочник горячих клавиш и специальных команд для работы в Bash. Все сочетания разбиты по функциональным группам: навигация по строке ввода, управление процессами, работа с историей, редактирование, автодополнение и специальные команды истории. В конце приведены практические рекомендации по запоминанию и разбор типичных вопросов.

---

## 1. Горячие клавиши — Базовые свойства

- **Контекст/Уровень:** Работа с командной строкой / Bash-оболочка.
- **Основное назначение:** Ускорение и упрощение повседневных операций в терминале.
- **Принцип работы:** Сочетания клавиш и специальные команды позволяют управлять курсором, процессами, историей и вводом текста без использования мыши.

> **Как запоминать:** Горячие клавиши не нужно заучивать все сразу. Они запоминаются естественно, по мере работы в терминале: сначала осваиваются базовые (`Tab`, `Ctrl+C`, `Ctrl+R`), затем добавляются новые по мере необходимости.

---

## 2. Навигация по строке ввода

| Сочетание клавиш      | Действие                                                             |
| :-------------------- | :------------------------------------------------------------------- |
| `Ctrl + A`            | Переместить курсор в начало строки.                                  |
| `Ctrl + E`            | Переместить курсор в конец строки.                                   |
| `Ctrl + F`            | Переместить курсор на один символ вперёд.                            |
| `Ctrl + B`            | Переместить курсор на один символ назад.                             |
| `Ctrl + XX`           | Переключить позицию курсора между началом строки и текущей позицией. |
| `Ctrl + ] + x`        | Переместить курсор вперёд к следующему вхождению символа `x`.        |
| `Alt + F` / `Esc + F` | Переместить курсор на одно слово вперёд.                             |
| `Alt + B` / `Esc + B` | Переместить курсор на одно слово назад.                              |
| `Alt + Ctrl + ] + x`  | Переместить курсор к предыдущему вхождению символа `x`.              |
*Таб. 1. Клавиши для навигации по строке ввода.*

> **Нюанс про `Ctrl + XX`:** Позволяет быстро переключаться между началом строки и текущей позицией. Полезно, когда нужно добавить что-то в начало строки, не перемещаясь туда вручную.

## 3. Управление терминалом и процессами

| Сочетание клавиш | Действие                                                       |
| :--------------- | :------------------------------------------------------------- |
| `Ctrl + L`       | Очистить экран терминала (аналог `clear`).                     |
| `Ctrl + S`       | Приостановить вывод команды на экран.                          |
| `Ctrl + Q`       | Возобновить вывод, приостановленный `Ctrl + S`.                |
| `Ctrl + Z`       | Приостановить выполнение текущей команды и отправить её в фон. |
| `Ctrl + C`       | Отправить сигнал `SIGINT` и завершить выполняющуюся команду.   |
| `Ctrl + D`       | Закрыть текущий терминал (отправить `EOF`).                    |
*Таб. 2. Клавиши для управления терминалом и процессами.*

> **Важно:** `Ctrl + S` и `Ctrl + Q` — это пара. Если вы случайно нажали `Ctrl + S` и терминал «завис», нажмите `Ctrl + Q`, чтобы разблокировать его.

## 4. Работа с историей команд

### 4.1. Горячие клавиши для поиска и навигации по истории

| Сочетание клавиш      | Действие                                                           |
| :-------------------- | :----------------------------------------------------------------- |
| `Ctrl + R`            | Инкрементный обратный поиск по истории.                            |
| `Alt + P`             | Неинкрементный обратный поиск по истории.                          |
| `Ctrl + J`            | Завершить поиск по истории, оставив текущую команду.               |
| `Ctrl + G`            | Выйти из режима поиска по истории.                                 |
| `Ctrl + _`            | Отменить последнее изменение в строке.                             |
| `Ctrl + P` / `↑`      | Перейти к предыдущей команде в истории.                            |
| `Ctrl + N` / `↓`      | Перейти к следующей команде в истории.                             |
| `Ctrl + S` (в поиске) | Перейти к следующей (более старой) команде в результатах поиска.   |
| `Ctrl + O`            | Выполнить найденную команду (через `Ctrl+R/S`) и продолжить поиск. |
*Таб. 3. Клавиши для поиска и навигации по истории.*

> **Нюанс про `Ctrl + R`:** Поиск начинается с последнего совпадения. Повторное нажатие `Ctrl + R` переходит к более ранним совпадениям. Это позволяет быстро найти нужную команду, но требует понимания направления поиска.

### 4.2. Специальные команды истории (вводятся в строке)

| Команда          | Действие                                                       |
| :--------------- | :------------------------------------------------------------- |
| `!!`             | Выполнить последнюю команду.                                   |
| `!*`             | Выполнить предыдущую команду, кроме первого слова.             |
| `!*:p`           | Показать, что подставит команда `!*` (без выполнения).         |
| `!x`             | Выполнить последнюю команду из истории, начинающуюся с `x`.    |
| `!x:p`           | Показать команду, начинающуюся с `x`, и добавить её в историю. |
| `!$` / `Alt + .` | Подставить последний аргумент предыдущей команды.              |
| `!$:p`           | Показать, что подставит `!$` (без выполнения).                 |
| `!^`             | Подставить первый аргумент предыдущей команды.                 |
| `^123^abc`       | Заменить в предыдущей команде `123` на `abc` и выполнить.      |
| `!n`             | Выполнить команду под номером `n` из истории.                  |
| `!n:p`           | Показать команду под номером `n` (без выполнения).             |
| `!n:m`           | Повторить аргументы с номера `n` по `m` из последней команды.  |
| `!n:$`           | Повторить аргументы от `n` до последнего из последней команды. |
| `!fi`            | Выполнить последнюю команду из истории, начинающуюся с `fi`.   |
*Таб. 4. Специальные команды для работы с историей.*

> **Примеры:**
> - `!!` — повторить последнюю команду.
> - `!$` — подставить последний аргумент предыдущей команды.
> - `^123^abc` — заменить `123` на `abc` в предыдущей команде.

## 5. Редактирование строки ввода

| Сочетание клавиш | Действие |
| :--- | :--- |
| `Ctrl + U` | Удалить от курсора до начала строки. |
| `Ctrl + K` | Удалить от курсора до конца строки. |
| `Ctrl + W` | Удалить слово/аргумент перед курсором. |
| `Ctrl + D` | Удалить символ под курсором (или закрыть терминал). |
| `Ctrl + H` | Удалить символ перед курсором (как `Backspace`). |
| `Alt + D` | Удалить от курсора до конца слова. |
| `Alt + Backspace` | Удалить от курсора до начала слова. |
| `Alt + .` / `Esc + .` | Вставить последний аргумент предыдущей команды. |
| `Alt + <` | Перейти к первой команде в истории. |
| `Alt + >` | Перейти к последней команде в истории. |
| `Esc + T` | Поменять местами два последних слова перед курсором. |
| `Alt + T` | Поменять местами текущее и предыдущее слово. |
*Таб. 5. Клавиши для редактирования строки ввода.*

> **Важно:** `Ctrl + D` имеет двойное действие: если строка не пуста — удаляет символ под курсором; если строка пуста — закрывает терминал. Будьте внимательны.

## 6. Автодополнение и информация

| Сочетание клавиш    | Действие                                                             |
| :------------------ | :------------------------------------------------------------------- |
| `Tab`               | Автодополнение команды или имени файла/каталога.                     |
| `Ctrl + I`          | Аналогично `Tab` (автодополнение).                                   |
| `~` затем `Tab Tab` | Показать список всех пользователей системы.                          |
| `Alt + ?`           | Показать список файлов и каталогов в текущем пути (справка).         |
| `Alt + *`           | Вставить имена всех файлов и каталогов в текущем пути как аргументы. |
*Таб. 6. Клавиши для автодополнения и информации.*

> **Нюанс про `Tab Tab`:** Двойное нажатие `Tab` показывает все доступные варианты автодополнения, включая команды, файлы и каталоги, начинающиеся с введённого фрагмента. Это работает не только для программ, но и для путей.

## 7. Расширенный ИБ-контекст и инженерный FAQ

### 1. Практические рекомендации

- **Не пытайтесь запомнить всё сразу.** Горячие клавиши входят в привычку постепенно. Начните с пяти-шести базовых (`Tab`, `Ctrl+C`, `Ctrl+R`, `Ctrl+L`, `Ctrl+U`, `Ctrl+K`) и добавляйте новые, когда почувствуете необходимость.
- **Используйте `history | grep` как альтернативу `Ctrl+R`.** Если интерактивный поиск вам неудобен, обычный `grep` по истории часто работает быстрее и предсказуемее.

### 2. Инженерный FAQ (На основе разбора дискуссий)

- **Вопрос:** *Как просто напечатанную строку полностью удалить, не смотря на положение курсора?*  
  **Ответ:** Используйте `Ctrl + U` (удалить до начала) и `Ctrl + K` (удалить до конца) последовательно. Либо `Ctrl + C` для прерывания.

- **Вопрос:** *~ затем Tab Tab — как-то странно работает.*  
  **Ответ:** Это работает, но только в контексте автодополнения путей. Попробуйте ввести `~` и дважды нажать `Tab` — должен появиться список пользователей системы. Если не работает, возможно, ваш терминал настроен иначе.

- **Вопрос:** *И что, кто-то пользуется хотя бы половиной этих горячих клавиш?*  
  **Ответ:** Да, довольно большое количество людей активно пользуется этими сочетаниями. Но никто не заучивает их все разом. Они запоминаются естественно, по мере работы в терминале: сначала осваиваете базовые (`Tab`, `Ctrl+C`, `Ctrl+R`, стрелки), потом замечаете, что какое-то действие можно сделать быстрее — подглядываете в памятку, пробуете, и через пару месяцев это уже на автомате.

- **Вопрос:** *Что такое «вхождение символа x» в комбинациях `Ctrl + ] + x`?*  
  **Ответ:** Это означает, что вы нажимаете `Ctrl + ]`, отпускаете, затем вводите нужный символ (например, `a`). Курсор перемещается к следующему вхождению этого символа в строке. Это полезно для быстрой навигации по длинным командам.

- **Вопрос:** *Почему в этом уроке так много горячих клавиш? Их реально все нужно запоминать?*  
  **Ответ:** Нет, их не нужно заучивать все сразу. Горячие клавиши запоминаются естественно, по мере работы. Начинайте с базовых (`Tab`, `Ctrl+C`, `Ctrl+R`, `Ctrl+L`) и постепенно добавляйте новые, когда заметите, что какое-то действие можно сделать быстрее.

- **Вопрос:** *Есть ли разница между `Alt + F` и `Esc + F` в терминале?*  
  **Ответ:** В большинстве современных терминалов `Alt` и `Esc` работают одинаково. Однако в некоторых старых или минималистичных окружениях `Esc` может быть единственным доступным вариантом. Это связано с тем, что `Alt` иногда перехватывается оконным менеджером, а `Esc` — нет.

## 8. Заключение

Горячие клавиши в Bash — это не просто удобство, а основной способ ускорить работу в терминале. В отличие от графических интерфейсов, где мышь является стандартом, в командной строке горячие клавиши заменяют её полностью. Изучение и практическое применение этих сочетаний позволяет сократить время на рутинные операции, повысить продуктивность и комфорт при работе с системой. Начинать стоит с базовых комбинаций — `Tab`, `Ctrl + C`, `Ctrl + R`, `Ctrl + L` — и постепенно добавлять новые по мере необходимости.
